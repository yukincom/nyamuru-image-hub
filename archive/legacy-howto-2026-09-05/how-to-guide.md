LLMと画像生成AIをつないで、テーマから完成漫画まで進む3ステップのワークフローです。Nyamuru 🐱 Image Hub（このアプリ）は真ん中に立って、ネーム（OMNY形式）の確認・調整を受け持ちます。

## とりあえず、あなたの創作パートナーのAIに聞いてみる

下の質問文をコピーして、いつも使っているAI（Claude・ChatGPTなど）に貼り付ければ、このアプリのことを案内してもらえます。

```
このリポジトリについて教えて！
https://github.com/yukincom/nyamuru-image-hub
```

## 作業の流れ

テーマ・原稿 → ネーム（OMNY） → 調整済みネーム → **完成漫画画像**

## STEP 1：LLMでネームを作る

**使うもの**：公開ドキュメントの完全版プロンプト ＋ お好みのLLM（Claude・ChatGPTなど）

1. 公開ドキュメントの生成プロンプト全文をコピーして、LLMのプロジェクト指示（またはシステム指示）に設定する
2. テーマ・あらすじ・台本と、ページ数や作風などの希望を伝える
3. LLMが出力したOMNY形式のネームを `.yaml` ファイルとして保存する

**できあがり**：OMNY形式のネームファイル（.yaml）

→ [生成プロンプトを開く](/docs/prompt/)

## STEP 2：このアプリで確認・調整する（任意・スキップ可）

**使うもの**：Nyamuru🐱 Manga Name Studio（このアプリ）

1. ヘッダーの「読み込み」からSTEP 1のOMNYファイルを開く
2. 「ネーム」タブでコマ割り・人物・フキダシの配置をドラッグで調整し、セリフや演出を手直しする
3. NDM検査でルール違反がないか確かめて、「OMNY保存」からストーリーOMNYを保存し直す

**できあがり**：調整済みのOMNYファイル（.yaml）

→ [ネームを開く](#tab-storyboard)

## 紙のネームからSTEP 2を始める

ローカル画像解析環境を起動している場合は、ヘッダーの「新規作成」から紙のネームを編集可能なページへ取り込めます。

1. 「画像を読み込む」または「スキャナーを起動」を選ぶ
2. 最大10枚の原画を確認し、必要な画像を手動で回転して正立させる
3. 上下・左右のコマ間隔と枠線の太さを入力する
4. 「解析開始」を押し、「原画」と「解析結果」を見比べる
5. 「編集開始」を押し、通常のネーム編集画面でコマ・人物・フキダシ・文字を直す

解析結果は完成データではなく、手直しの開始地点です。文字の誤読、不要なコマ、人物あたりの位置を確認してからOMNYを保存してください。画像を選んだだけでは解析は始まらず、「解析開始」を押したときだけ同じ端末のローカルbridgeへ送られます。

ネーム画面では次の補助を切り替えられます。

- **内枠スナップ**: コマをページの内枠へ吸着
- **コマスナップ**: コマを作品設定の上下・左右間隔へ吸着
- **コマシンクロ**: 接合する頂点や揃った境界を局所的に追従

コマシンクロで意図しない追従になる複雑な配置は、コマシンクロをOFFにし、コマスナップとShift＋ドラッグの水平・垂直移動で調整してください。

## STEP 3：画像生成AIで漫画にする

**使うもの**：公開ドキュメントの生成ワークフロー ＋ 「作品情報」タブのスタイルOMNY ＋ キャラ・背景のリファレンス画像 ＋ 画像生成できるAIエージェント（GPT Workなど）

1. 公開ドキュメントの生成ワークフローと、「作品情報」タブのスタイルOMNYを、エージェントが参照できる場所に配置してプロジェクト指示を設定する（初回のみ。以降の作品はストーリーOMNYを渡すだけ）
2. OMNYファイルとリファレンス画像を渡して、漫画生成を依頼する
3. エージェントがページ単位で作画・検品・再生成して、完成画像を納品する

**できあがり**：ページごとの完成漫画画像（PNG）

→ [生成ワークフローを開く](/docs/workflow/)

## ワンポイントアドバイス

### LLMを使わずにOMNYを一から作ることもできます

Nyamuru🐱 Manga Name Studioがあれば、STEP 1を飛ばしてゼロからのネーム作りも可能です。ヘッダーの「新規作成」でコマ割りパターンを選び、[「ネーム」タブ](#tab-storyboard)でコマ・人物・フキダシを配置して、セリフや演出を書き込めば、そのままSTEP 3へ渡せるOMNYファイルを書き出せます。

### まずは手ぶらで試すなら

このアプリに入っているサンプル漫画をヘッダーの「ストーリー保存」でストーリーOMNYにして、[公開ドキュメントの「にゃむるたん」](/docs/nyamurutan/)にある立ち絵画像と一緒にエージェントへ渡せば、STEP 3だけをすぐ体験できます。

### Claude Codeなら、ネーム設計から納品まで任せられるスキルもあります

姉妹プロジェクトの [rimochan-nyamuru-manga-forge](https://github.com/sa-san10/rimochan-nyamuru-manga-forge) は、「5ページで、こういう話の漫画を描いて」と自然言語で頼むだけで、ネームの設計→作画→検品→納品まで進むClaude Code用スキルです。同じOMNY形式なので、このアプリで整えたネームをそのまま渡して原稿化することもできます。

### 作品固有の画風・ルールはスタイルOMNYで管理

作品固有の画風・ルールは、[「作品情報」タブ](#tab-meta)の「スタイルOMNYを保存」でファイルへ保存し、作品ごとに管理してください（読み込みも同じ場所からできます）。保存ファイルの内部形式はOMAYです。

### スタンドアロン版もあります

CSS・JS・アイコンまで全部入りの単一HTMLファイル版です。ダウンロードしたファイルをダブルクリックするだけで、サーバー不要・オフラインで起動します。USBメモリで持ち運んだり、ネットのない環境でネームを編集したいときにどうぞ。再配布するときは [THIRD_PARTY_NOTICES.txt](/standalone/THIRD_PARTY_NOTICES.txt) を一緒に添付してください。

→ [スタンドアロン版をダウンロード](/standalone/nyamuru-image-hub.html)（スタンドアロン版で開いているときは、代わりに配布元リポジトリ（GitHub）を開きます）
