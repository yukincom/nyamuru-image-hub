# アナログネーム取り込みサンプル

本フォークで、紙のネームを編集可能なOMNYへ取り込む流れを示すサンプルです。

| ファイル | 内容 |
|---|---|
| `scan01.jpeg` / `scan02.jpeg` | 取り込み元のアナログネーム |
| `page01.png` / `page02.png` | コマ・人物あたり・フキダシ候補を反映した解析結果 |
| `sample.mov` | 画像の読み込みから解析、編集開始までの操作動画 |

解析結果にはOCRの誤読や位置のずれが含まれることがあります。完成データではなく、原画と見比べながら修正するための開始地点として使用します。
