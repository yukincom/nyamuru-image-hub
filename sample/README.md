# アナログネーム取り込みサンプル

本フォークで、紙のネームを編集可能なOMNYへ取り込む流れを示すサンプルです。

| ファイル | 内容 |
|---|---|
| `scan01.jpeg` / `scan02.jpeg` | 取り込み元のアナログネーム |
| `page01.png` | 編集画面の見開きから切り出した右ページ（READMEの原画に対応） |
| `page01-before.png` | `page01.png`を改善する前の解析結果 |
| `page02.png` | 2ページ目のコマ・人物あたり・フキダシ候補を反映した解析結果 |
| `editor-workspace.png` | ページ一覧、見開きの原稿、レイヤーとコマ情報を並べた編集画面 |
| `three-image-generation.png` | 3D・キャラクター設定画・ネームを参照する人物生成画面 |
| `pose-editor.png` | ポーズアセットとモーションサポーターを使う3D編集画面 |
| `sample.mov` | 画像の読み込みから解析、編集開始までの操作動画 |

解析結果にはOCRの誤読や位置のずれが含まれることがあります。完成データではなく、原画と見比べながら修正するための開始地点として使用します。
