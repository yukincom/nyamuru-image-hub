# フォルダー操作と環境設定（2026-10-23）

## 作品の入口・保存

- 起動時は「新規作成」「作品フォルダを開く」。右上の新規ボタンも中央と同じ緑色。
- 通常起動版・LAN版とも作品フォルダーを選ぶ。LAN版の新規作成はエピソードフォルダー必須。
- 「ファイル」メニュー、単独作品ファイルの読込・書き出し、OMNYの単独読込、非対応ブラウザーのファイル保存代替を撤去。別名の `.nyamuru` を探して開く経路も持たない。
- LAN版の保存実体はフォルダー内の `作品.nyamuru`。画像等を保持する保存コーデックは通常保存のために使う。通常起動版の `.nyamuru/project.json` との相互変換は行わない。
- 「OMNY書き出し」は環境設定のデータ管理に置く。既存のOMNYシリアライザーを使い、構成・セリフを書き出す。画像原本・作画設定を含むバックアップではない。

## 環境設定の表示と保存

右上の緑の歯車から、起動画面・新規作成中・編集中の上に設定を重ねる。同じ位置のオレンジ色の×、背景クリック、Escapeで閉じる。背面の編集画面と新規作成の入力を保持する。ペイント中は描画を確定してから開き、作品設定変更で未確定描画の保存先が古くならないようにする。設定表示中は背面の操作を止め、Tab移動を設定と閉じるボタンに限定する。

端末設定は変更時または入力欄から離れた時点で保存する。Escapeでも入力欄の確定を先に行う。作品固有のレイアウト等は編集中の作品へ反映し、作品フォルダーへの保存は通常の「保存」で行う。作品を開く前と新規作成中は端末設定を表示する。

モデル設定はロボットアイコンにする。エージェントの音声説明・無音待ち時間のUIを置かず、既存の音声入力動作と保存済みの待ち時間は保持する。スクロール領域の下端には64pxの余白を取る。

## 用語方針

利用者向けの設定名・説明・エラー・案内では、一般名称を「モデル」に統一する。「AI」「SI」は一般名称として使わない。実際に操作を行う役割は「エージェント」と呼ぶ。製品・組織・モデルの正式名称、外部仕様の識別子、引用、過去の記録は原文を保持する。コードの識別子や保存キーは表示名の変更だけを理由に改名しない。

## ローカル画像生成と内蔵エージェント

通常の画像生成本体はQwen-Image-2.1 Turboに統一する。これに指示文・参照画像のエンコーダーと、結果を画像へ変換するVAEを組み合わせる。モデルファイル3件はこの役割分担であり、通常版など複数の生成本体の併用を意味しない。設定画面でも「生成本体と補助モデル」として役割を明記する。

専用PythonからComfyUIのノード・生成処理を直接呼ぶ。起動中のComfyUI HTTPサーバーへ投げる構成ではない。環境設定の「ローカル画像生成」で、既存 `QwenGenerationService.preflight` による実行環境・モデルファイル確認、使用モデル・ステップ数・基準解像度の表示を行う。これは推論成功の検証とは区別する。

「別に起動したComfyUIへの接続」は端末のモデル設定にURLを保存する。空欄はbridgeの起動設定を使う。URLは処理するMac上のloopback HTTPとポートに限定し、資格情報・任意パス・query・fragment・外部宛先を拒否する。明示的な接続確認で `/system_stats` だけを読み、proxyとredirectを使わない。通常のQwen生成先や既存のComfyUIラフ生成ジョブの接続先を変更しない。

共通の読取窓口は `POST /api/image-generation/connections`。起動管理の利用セッションを取得し、終了時に解放する。モデル読込・サーバーへの画像生成依頼は行わない。内蔵エージェントには同じ窓口を呼ぶ `model_connections` を公開する。接続先や実行命令をツール引数で上書きさせず、端末に保存した設定を使う。LANではこの確認APIだけを公開し、Macの作品保存先に依存する `/api/panel-draft/*` は公開しない。

「エージェントに接続」、または設定内の同じエージェントへ「画像生成をつないで」で、実行環境を確認してQwen Turboを端末の生成先に登録する。会話と設定は同じ接続処理を使い、ファイル不足・取消し・設定保存失敗を成功として返さない。保存済みの設定は推論成功の証明とは扱わない。

内蔵ツール `image_generation` は `connect` と `generate` を扱う。会話の文章LLM利用を解放してから処理し、画像生成中のLLM一時停止と競合させない。生成対象の明示的な操作は既存の `generate_selected` へ渡す。登録人物資料を読み込み、既存の英訳保存・Qwen生成・結果照合・元のあたりへの差し込みまで実行する。条件不足は準備画面と会話に理由を表示する。生成の質問・否定・複数操作では生成を実行せず、待機中の原稿／選択変更や会話終了でも新たな送信・自動挿入を止める。別のジョブを自動再送しない。差し込みは通常の元に戻す／やり直すで扱う。

設定内の会話は既存エージェントの表示先だけを移すため、会話履歴と進行中の処理を保持する。Codexやクラウドエージェントを画像生成の実行に使わない。`model_connections` の状態確認はコード側の要約を優先し、未接続の結果を会話モデルの文章で成功に置き換えない。
