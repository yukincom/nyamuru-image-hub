# シリーズ人物画像の引き継ぎ

- 利用者報告：新規作成の人物画像追加で `同名で別IDのシリーズ項目があります: koyuki.png` と表示される。
- 保存済みの同じシリーズ台帳には `koyuki.png` と人物の安定IDがある一方、作成中の人物欄に画像が表示されていなかった。
- `continueFromSeriesSelection` は「既存シリーズ」の場合だけ台帳を読み込んでいた。「新しいシリーズ」でも保存済みと同じシリーズ名なら、後の保存は既存台帳を使うため、画像だけが新しいIDで二重登録されて衝突していた。
- 新規作成でも既存の `mergeSavedSeriesCatalog` を通し、同じシリーズの人物・画像・安定IDを引き継ぐ。台帳がなければ既存の空ドラフト処理を使う。
- 実handlerを使った対象テスト1件で、既存画像・所有人物・代表画像のIDを保持し、画像を重複させず引き継ぐことを確認した。テストではフォルダー選択や実ファイル保存を行っていない。
- 利用者が新規作成を進め直し、小雪の `koyuki.png` が登場人物欄に「表示された」と確認した（2026-10-27）。保存済み台帳・原画像への直接変更は行っていない。全体ビルド・全件テストは実行していない。
