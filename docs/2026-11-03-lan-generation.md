# LAN版の人物生成と背景透過（2026-11-03）

LAN版は起動時に通常版と共通の編集画面をビルドする。人物生成で不足していたComfyUIの起動・進捗確認・終了を、既存のHTTPS中継からMac Studioの起動管理へ渡す。生成画面を閉じるときの停止通知も同じ経路を使う。候補の透過・採用には通常版の処理を使う。[LAN版の操作手順](./LAN_EDITING.md#6-人物を生成する)

## 確認した範囲

| 確認方法 | 結果 |
|---|---|
| LAN版の起動 | Mac上で `npm run lan -- --host 127.0.0.1` を実行。ChromeでHTTPSの編集画面を表示し、配信された表情辞書の見本10枚が元画像と一致した。 |
| 実際のComfyUI | LAN版のHTTPS経由で起動し、進捗監視のWebSocketに接続。タブ離脱時と同じ形式の停止通知でプロセスが終了し、ポート8188が解放された。 |
| 関連テスト | Node 32件、Python 15件成功。中継先・本文・別サイトからの拒否を確認。合成画像で背景のアルファ値と内部色、透過済み候補の選択と採用の再試行を検証した。 |
| LAN設定のChrome画面テスト | 表情辞書8項目と生成候補38項目に合格。生成候補は模擬応答を使い、5枚から2枚目・4枚目を選んでまとめて追加する操作、失敗・中断時の挙動を確認した。 |

別の物理端末からの接続と、実作品を使ったモデルの新規生成は未確認。検証用のLANサーバーと画面テスト用サーバーは停止済み。
