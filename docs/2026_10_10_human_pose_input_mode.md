# ポーズの送り方の選択UI

2026-10-10 / 状態: 利用者了承後、関連Node42件・型検査・通常/単一HTMLビルドとコマ内/ページ前景の実画面を確認。生成への送信は後続。

基点は体勢反転の検証済みcommit `e02d4ca`。[P5計画](2026_10_08_human_pose_p5_generation_integration.md)の送り方選択と、選択時の日本語へ戻す操作を実装する。

## 実装範囲

- 人物のポーズ欄に「プロンプトで送る」「撮影画像で送る」のradio選択を追加する。コマ内とページ前景が使う既存 `FigureHumanPoseEditor` へ接続する。
- 既存の `Figure.human_pose.input_mode` と型・validation・normalize・OMNY保存・Undo経路を使う。新しいfield、API、job storeは作らない。
- 初めてポーズを選ぶときは既存規則どおり `prompt`。送り方だけを変更した場合、基準日英、日本語編集文、pose ID、素材版、配置、camera、反転状態は保持する。同じradioの再選択では文書更新を呼ばない。
- 文章を使う場合と撮影画像を使う場合の違いを通常の人物欄で説明する。画像を選んでいても文面を編集・保存できるが、その文は画像と一緒に送らないことを表示する。モード変更による3Dの自動変形はない。
- 「選択時の文に戻す」は保存済みの基準日本語を使い、日本語編集文だけを戻す。今のcatalogを読み直して更新する操作ではない。既存のUndoで取り消せる。同文なら無効化する。
- 別ポーズを確定する場合は従来の選び直し規則を維持し、初期の文章モードになる。同じポーズの再選択では送り方も保持する。

## まだ送信できない範囲

この変更は送り方の選択と保存まで。生成機能が準備中である表示と `requireHumanPoseGenerationReady` を維持し、両モードとも未接続のポーズ指定を黙って捨てて生成することを防ぐ。

画像モードを選んでも、素材の `image_reference_eligible` や利用者の画像確認を通過した扱いにはしない。現行catalogの画像参照可否を再評価しておらず、PNGは3Dダイアログ内のプレビューのみ。PNG/job保存、全指示確認、画像参照可否の判定、pose role、差分英訳、Qwen送信は後続。

- 型検査は330ファイル、error/warning/hint 0。通常/単一HTMLビルドとも成功。共通の実行コマンドと確認範囲は[カメラ操作の記録](2026_10_10_human_pose_camera_controls.md)に記載する。

- radioの矢印キー操作で切り替えても編集文とsceneを保持。同じポーズの再確定で編集文・送り方・sceneが保持される。別ポーズの確定ではpromptとその基準文へ戻る。コマ内/ページ前景ともOMNY再読込で保存値が復元され、3D再open後の撮影PNGも一致した。
