# コード入力なしのLAN接続 — 2026-10-20

自宅のLAN内で使うたびに接続コードを入力する手間をなくすため、LAN版のコード認証とログイン画面を廃止しました。Mac Studioで `npm run lan` を起動し、編集PCで表示されたHTTPSのURLを開くと、そのまま編集画面に進みます。特別な起動オプションやブラウザーのログインCookieは必要ありません。

## 操作と反映

利用者が起動しているサーバーを、そのターミナルで `Ctrl+C` で終了し、同じ起動コマンドで起動し直します。編集PCではページを再読み込みします。コード変更用の `--reset-code` オプションは不要になりました。

初回の証明書登録と作品の保存方法は同じです。作品は編集PCへ保存します。保存済みの `.local-vision/lan-access-code` は読み書きせず、起動に使いません。ファイルを自動削除する処理もありません。

## 接続の範囲

同じLAN内の端末はコードなしで画面と許可済みのAI処理を利用できます。HTTPS、LAN接続元・Host・Originの確認、別サイトからのAPI操作の拒否は継続します。外部リンクからトップ画面へ移動するGETだけを許可し、iframeや画像・スクリプト・fetch経由の別サイト要求は拒否します。

Macの作品フォルダ・ファイル選択・スキャナーなどの操作は引き続きLAN入口で拒否します。内部bridgeと文章LLMの待受や、ルーター・ファイアウォールの設定は変更しません。
