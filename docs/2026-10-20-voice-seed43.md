# seed43による保存・ページ移動（2026-10-20）

**採用決定：通常学習v0.4のseed43（trial-4、epoch8）をニャムルの操作分類器に採用する。** 2026-10-20のユーザー指定に基づく。v0.5.1 baselineの同じseedと同一重みで、旧v0.2のseed43とは別のモデル。日常112問は110問正解、従来73問は60問正解だった。

2026-10-24追記：現在は分類モデルを本体へ同梱し、bridge自身のPythonで実行します。[現在の導入手順](2026-10-24-classifier-bundle.md)を参照してください。以下の導入環境・検証は採用当時の記録です。

## 操作

原稿を開き、エージェントの入力欄へ「保存して」または「次のページ」と入力して送信する。通常のマイクは文字起こしを確認して送信する手動入力。時計付きマイクは、オンの間、発話ごとに自動送信・実行する軽量対話。操作は[ハンズフリーの軽量対話](2026-10-20-voice-hands-free.md)を参照。

- 「保存して」は通常の保存ボタンと同じ処理を呼ぶ。保存先が未指定ならフォルダ選択を行い、完了・キャンセル・失敗をそのまま表示する。
- 「次のページ」はページ一覧と同じ処理で一つ先へ移動する。最終ページでは「指定されたページがありません」と表示する。
- この2操作の完了表示にLLMの起動・応答は必要ない。分類・引数確認と、原稿や選択の変更を検出する既存の処理を通す。

これは分類の接続と実行処理の検証であり、日常112問すべての言い換えを実行可能にしたものではない。分類後に全文と引数を確認し、複数操作・引用・否定などを単語一致だけで実行しない。0.9未満は従来どおり保留する。

## モデル導入

評価済みのcheckpointディレクトリを指定する。ネットワーク取得やパッケージ追加は不要。

```sh
python3 scripts/install_voice_intent.py /path/to/v04-results/weights/trial-4/best
npm run dev
```

インストーラーは4ファイルのSHA256と19ラベルの順序を確認し、`models/nyamuru-voice-v04-seed43/`へ重みと出典を保存する。異なる既存ファイルを上書きしない。旧`models/nyamuru-voice-v02/`は保持し、重みはGitに含めない。

重みSHA256: `1cb98d06dffde79f234a29b1c78e679634aae6e1357272c85948da6d57c3c3e1`。

既定の分類用Pythonは兄弟の`ComfyUI/.venv/bin/python`。`NYAMURU_VOICE_INTENT_PYTHON`・`NYAMURU_VOICE_INTENT_MODEL`の明示指定は保持する。既存の`/api/voice/classify`で原文だけを分類し、操作はブラウザー内の既存ハンドラへ渡す。作品ファイルを分類器から直接変更しない。

CPU float32、SDPA、推論時dropout無効、4 threads、128 tokenまで・切り詰めなし。上限を超える文は、分類器が切り詰めずにエラーを返す。分類できない入力を既存のLLM会話へ引き継ぐ動作は維持する。

## 検証

アプリの既存環境（Python 3.11.14、torch 2.11.0、transformers 5.14.1）で日常112問と従来73問を再推論した。16件ずつの推論は185件すべてのラベル・確率が評価記録と一致。アプリと同じ1件ずつでも185件のラベルが一致し、確率の最大差は0.000004709だった。

既存の検証画面（`tests/voiceCommands.browser.html?seed43`、専用オリジン4338）から、実際のApp・分類API・編集ハンドラを通して確認した。分類結果や保存応答の差し替えは行っていない。

- 「次のページ」：1ページ目から2ページ目へ移動し、「2ページを表示しました」と表示。
- 最終ページでもう一度「次のページ」：「指定されたページがありません」と表示し、2ページ目を維持。
- 「保存して」：macOSのフォルダ選択後、「manga に保存しました」と表示。実際の `.nyamuru/project.json` を読み、検証原稿ID `voice-seed43-fixture-20261020`、2ページ、画像assets 0件を確認した。
- macOSのKyokoで生成した合成音声2本を既存のWhisper APIで認識し、それぞれ「保存して」「次のページ」と一致。続く実分類APIは `save` / `page_navigate` とモデル名 `nyamuru-voice-v04-seed43` を返した。これは音声ファイルの認識と分類であり、マイク録音を通した操作確認ではない。

保存原稿SHA256：`9474aa68783e67a74e7aa7e81e011883e28bf9979dfa80050e0c73866a5dd639`。移動前後で一致。記録は 保存先の修復記録（ローカル資料 `../output/voice-seed43-2026-10-20/save-relocation.json`、配布対象外）、保存・ページ移動の画面（ローカル資料 `../output/voice-seed43-2026-10-20/save-page-ui-before-relocation.jpg`、配布対象外）、後片付け画面（ローカル資料 `../output/voice-seed43-2026-10-20/cleanup-ui.jpg`、配布対象外）、合成音声の認識・分類（ローカル資料 `../output/voice-seed43-2026-10-20/audio/transcriptions.json`、配布対象外）。これらはローカルの検証成果物で、Gitには含めない。
