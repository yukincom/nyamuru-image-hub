# アナログネーム人物切り抜き仕様

## 目的

紙または画像のネームから検出した人物領域を、編集可能な人物あたりの位置情報と実画像の切り抜きでひとまとまりにする。

このデータはNyamuruのOMNYとは分離したローカル中間データとして保持する。将来、CLIP STUDIO PAINTなどへ接続するアダプターは、この中間データを各アプリ固有のレイヤー表現へ変換する。

## 対象範囲

- RT-DETRが検出した `body` / `face` 領域を使用する。
- 読み込み時にユーザーが指定した0° / 90° / 180° / 270°の向きを反映して切り抜く。
- 切り抜き画像は色変換、白の透明化、不透明度変更、描画モード変更を行わない。
- 人物の同定、衣装・髪型・表情・ポーズの言語化、キャラクター資料との照合は行わない。これらは将来の画像解析機能の対象とする。

## データ構造

人物あたりには、次のローカル専用メタデータを関連付ける。

- `sourceRegionId`: 解析元ページ内で人物領域を一意に識別するID
- `assetId`: IndexedDBに保存した切り抜き画像のID
- `sourceBBox`: 正立させた原画上の正規化座標
- `detectionSource`: `body` または `face`
- `confidence`: 検出器から得られた場合だけ保存する信頼度
- `draft`: 常に `true`
- `userEdited`: 人物あたりの位置・大きさをユーザーが変更した場合に `true`

切り抜き画像本体はブラウザのIndexedDBへ保存する。OMNYのコピー、YAML表示、YAML書き出しには、上記メタデータと画像本体を含めない。

## 生成と表示

1. ユーザーが原画の向きを確認して解析を開始する。
2. RT-DETRが人物領域を返す。
3. 「編集開始」で正立後の原画から人物領域を切り抜き、IndexedDBへ保存する。
4. 人物あたりを所属コマへ配置し、同じ検出領域の切り抜き画像を人物あたりの枠内に表示する。
5. 人物あたりの移動・拡縮後も、同じ切り抜き画像との関連を維持する。

スキャン元は、切り抜き画像と編集可能データの保存が成功し、ユーザーが「編集開始」を確定した後に破棄する。処理に失敗した場合は原画を破棄せず、再試行できる状態を保つ。

## コマ合体時の重複整理

コマ合体で複数の人物あたりが同じコマへ集まる場合は、次の順で重複を整理する。

1. `sourceRegionId` が同じものは同一検出領域として扱う。
2. IDのないデータは、人物枠の重なりが十分に大きい場合だけ重複候補とする。
3. 残す優先順位は、ユーザー編集済み、`body`、信頼度、安定した小さいIDの順とする。
4. 異なる人物が近接しているだけの場合は削除しない。

コマ番号や人物配列の添字だけを重複判定に使わない。

## 将来のCLIP STUDIO PAINT接続

CLIP STUDIO PAINT側の仕様が確認できた段階で、ローカル中間データから次を生成する。

- 人物切り抜き画像を配置したレイヤー
- 人物あたりの位置・大きさ
- 下書きレイヤーフラグ

白の透明化、不透明度、乗算、グレースケール変換はNyamuru側では固定せず、接続先またはユーザーの作業設定へ委ねる。
