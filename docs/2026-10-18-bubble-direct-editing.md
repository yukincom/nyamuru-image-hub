# 吹き出し素材・直接文字編集 — 2026-10-18

## 操作

- Tツール、選択中の文字設定、フキダシ情報の「素材から入れ替え」から、既存38素材のウィンドウを開く。
- 素材をフキダシにドラッグして重ねる、またはフキダシを選択して素材をクリックすると、`bezier` のみ入れ替える。本文、文字設定、寸法、位置、発話種別、話者、しっぽ、結合を保持する。原稿には一つのフキダシとして保存し、Undo / Redoに対応する。
- 2026-10-26更新: 通常の選択ツールでは文字の上をダブルクリック、Tツールでは1回クリックで本文を直接編集する。Tでコマ内の空き領域をクリックすると、そのコマ所属の新規文字レイヤーを作成する。書体、サイズpt（スライダー／数値直接入力）、太さ、縦横を文字設定で操作する。本文の一部分を選んだ場合は、その範囲だけ太さを設定する。
- 書体や文字量から素材・寸法を自動選択しない。作者が指定したptを文字量や素材変更で自動縮小しない。pt未指定の原稿は編集開始時の表示サイズをポイント値として固定する。
- フキダシ情報から重複プレビューを除き、輪郭の詳細編集・強調語などを「輪郭と補足情報」へまとめる。

## 保存経路

画面とAI操作は既存のOMNYを編集する。`text_style` と `text_weights` は本文と同じオブジェクトに保存し、コマ内フキダシ、ページ前景、画面内文字に対応する。別の文字データや画像化した文字を正本にしない。原稿から独立したUI操作である素材ウィンドウ表示は履歴に原稿変更を追加しない。

直接入力は編集前の選択範囲を使って太字位置を更新する。同じ文字が続く場合も編集箇所を保持する。改行・貼り付けはプレーンテキストとし、IME変換は確定時に反映する。編集中のUndo / Redoも原稿の共通履歴を使う。全文だけを渡す外部の本文変更は共通接頭辞・接尾辞による差分を使う。

## BERT

既存の `view_change` と `resolveVoiceCommand` → `applyVoiceCommand` を使う。高確信度かつ一つの肯定依頼でウィンドウを開き、LLMを呼ばず固定の完了文を返す。分類を確定できない素材表示依頼は言い換えを案内する。LLMへ素材選択の `material` 指定を渡す機能を外し、素材ウィンドウ表示のLLMツールは追加しない。分類ラベルと採用モデルを変更しない。
