# 2026-10-27 ブラウザーへの作品自動保存・自動復元を撤去

## 範囲

利用者の依頼に従い、作品本文・作業画像・ブラウザー側シリーズ台帳・作品フォルダーの紐付けをブラウザーの永続ストレージへ保存しない。編集中だけメモリーに保持し、起動時は作品未選択にする。既存の明示的なフォルダー保存・読み込み、形式検証、保存先の競合検査を使う。

前担当の編集予約は利用者の指示で解除した。前担当の作業計画は引き継がず、既存の未commit変更・作品フォルダー・端末設定・描画機能にはこの作業から変更を加えない。過去のブラウザー保存データは参照せず、自動消去もしない。

## 実装と確認

- 入口：既存の「保存」「作品フォルダを開く」、人物・舞台設定の明示保存。
- 撤去：作品のlocalStorage reader/writer、編集350ms後の保存、IndexedDBへの作業画像等の保持。
- 画像寿命：現在の作品・Undo/Redo・処理中の画像をメモリーで保持し、既存の保存snapshotに含める。
- 合格条件：古いブラウザー作品を開かない、編集で永続書込を行わない、明示保存・読込の往復と失敗時の編集保持が通る。
- 関連Node試験96件成功：起動時の保存データ不参照、IndexedDB禁止下での画像・台帳・フォルダー操作、画像を含むsnapshot往復、保存先の競合、保存失敗・キャンセル、Undo/Redoの画像保持。
