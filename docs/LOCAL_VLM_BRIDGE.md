# ローカルVLM連携

新規作成画面では、紙のネームを画像として読み込み、画像処理でコマ枠候補を抽出したうえで、Mac内のQwen3-VLに既定のコマ割りパターンA〜Yとの比較を依頼できます。

画像はファイルを選択しただけではVLMへ渡されません。「VLMでコマ割りを判定」を押した時だけ、`127.0.0.1`で待ち受けるローカル連携へ送られます。外部サービスへの送信は行いません。判定結果は候補表示に留め、利用者が確認してから新規作成へ反映します。

## 起動

別のターミナルで次を実行します。

```bash
npm run bridge
```

環境確認だけを行う場合は次を使います。

```bash
npm run bridge:check
```

既定ではリポジトリと同じ親フォルダにある `ComfyUI-current`、`ComfyUI-v0.32.0`、`ComfyUI` の順で探索します。別の場所にある場合は `NYAMURU_COMFY_ROOT` にComfyUIルートを指定します。

## スキャナー

「スキャナーを起動」は、ローカル連携からmacOS標準のイメージキャプチャを開きます。取り込んだ画像は利用者が保存先を選び、その後「画像を読み込む」から指定します。ブラウザが保存先を監視したり、任意のファイルを自動送信したりすることはありません。

## 接続範囲

ローカル連携は `127.0.0.1:8787` のみに待ち受け、`localhost`または`127.0.0.1`で開いたNyamuruからのリクエストだけを受け付けます。
