# ローカル画像解析連携

新規作成画面では、紙のネーム画像を最大10枚まで読み込み、次の役割分担で解析します。

- RT-DETR（manga-babble-maker）: コマ・文字領域の検出
- RT-DETRの顔・身体・文字領域: コマ候補と同一領域にある誤検出の除外
- OpenCV: RT-DETRがコマを検出できない場合だけ使う輪郭補助
- NDLOCR-Lite: 検出した領域の手書き文字認識
- 手動確認: 解析前にすべての画像を正立させ、0°・90°・180°・270°の向きを確定
- Qwen3-VL: OCRの明示的な比較評価だけ（通常解析では起動しない）

画像はファイルを選択しただけでは解析処理へ渡されません。利用者が各画像をプレビューで正立させて「この向きを使用」を押した後、「ローカル解析」を押した時だけ、`127.0.0.1`で待ち受けるローカル連携へ1枚ずつ送られます。外部サービスへの送信は行いません。向き指定がない解析要求はbridge側でも拒否します。検出したコマはA〜Zのテンプレートへ分類・変換せず、正規化した矩形座標をそのまま編集可能なコマとして新規ページへ反映します。A〜Zは手動で開始する場合のプリセットとして残ります。文字候補は位置に対応するコマの編集可能なフキダシとして配置します。誤読を前提に、低確信度またはQwen補助の文字は画面で「要確認」と表示します。

ファイル選択で読み込んだ元画像は変更・削除しません。解析用の一時画像は各処理の終了時に削除します。プレビュー用の一時File、Object URL、回転情報、判定結果はブラウザ保存へ含めず、検出コマからページ作成を確定した時または新規作成画面を閉じた時に破棄します。

## 起動

別のターミナルで次を実行します。

```bash
npm run bridge
```

環境確認だけを行う場合は次を使います。

```bash
npm run bridge:check
```

既定ではリポジトリと同じ親フォルダにある `ComfyUI-current`、`ComfyUI-v0.32.0`、`ComfyUI` の順で探索します。別の場所にある場合は `NYAMURU_COMFY_ROOT` にComfyUIルートを指定します。

既定の専用環境は、同じ親フォルダの `manga-babble-maker` と `ndlocr-lite` です。それぞれ独立した `.venv` で一回限りのワーカーを実行するため、ComfyUIのPython依存関係とは混在しません。場所を変える場合は `NYAMURU_MANGA_BABBLE_ROOT`、`NYAMURU_NDLOCR_ROOT` を指定します。モデル重みはNyamuruへコピーしません。

Qwenの使用範囲は起動時に切り替えられます。

```bash
npm run bridge -- --qwen-mode off      # 専用検出器のみ
npm run bridge -- --qwen-mode auto     # offと同じ通常運用（既定、互換性のため名称を維持）
npm run bridge -- --qwen-mode compare  # OCRをQwenとも毎回比較
```

`auto`は8Bモデルを自動起動しません。向きはQwenを含むモデルで推定せず、常に利用者が確定します。コマ検出にもQwenを使用しません。`compare`で得たOCR提案は元の専用OCR結果と紐付け、明らかな文字化けを置き換える場合も「要確認」のままにします。関連ライセンスとモデル配置方針は `docs/LOCAL_VISION_COMPONENTS.md` を参照してください。

## スキャナー

「スキャナーを起動」は、ローカル連携からmacOS標準のイメージキャプチャを開き、開始時刻から5分間、イメージキャプチャに設定されている保存先を監視します。書類名の接頭辞（標準では「スキャン」）と一致し、開始後に新規作成され、書き込みが完了した画像だけを時刻順に最大10枚取り込みます。

取り込んだスキャン元ファイルは、利用者が検出結果を確認して「このコマから編集を開始」または複数ページの開始ボタンを押すまで保存先に残します。ページ作成を確定した場合に加え、新規作成画面を明示的に閉じた場合、手動画像へ切り替えた場合、または「破棄する」を選んだ場合は、そのセッションで取り込んだスキャン元ファイルを削除します。開始前から存在するファイル、接頭辞が異なるファイル、11枚目以降のファイルは削除しません。

ブラウザの再読み込み、アプリやローカル連携の強制終了では、スキャン元を削除しません。ローカル連携は画像本体ではなく、開始時刻・保存先・対象ファイル名だけを `~/Library/Application Support/Nyamuru Manga Name Studio/scanner-session.json` に記録します。次に新規作成画面を開くと「前回のスキャン画像が残っています」と表示し、「つなぎ直す」または「破棄する」を選べます。

## 接続範囲

ローカル連携は `127.0.0.1:8787` のみに待ち受け、`localhost`または`127.0.0.1`で開いたNyamuruからのリクエストだけを受け付けます。
