# Qwen・別マスクを含む3枚入力のメモリ対策（2026-10-13）

利用者依頼：原画・別マスク・人物設定画の3枚を、既存のメモリ上限内で生成する。追加確認：1枚のマスクで離れた2か所を指定できるか。開始時HEADは `3a313b1`。前回の失敗と局所編集比較は [前回の検証記録](2026_10_13_qwen_local_edit_real.md) を参照。

## 原因と変更

インストール済みComfyUIでは、MPSの既定attention `attention_sub_quad` が一時的な計算領域の大きさを `model_management.get_free_memory()` から決める。この関数はMPSではシステム全体の空きメモリを返すため、生成ワーカーに設定した16 GiBの割り当て上限と一致しない。前回の3枚入力では、13.15 GiB使用中に4.12 GiBを追加要求して停止した。

既存の `ModelAttentionBackend` が使うモデル単位の切り替え機能を再利用し、生成ワーカーのモデルに `get_attention_function('pytorch')` を設定する。独自attentionの追加やComfyUIの変更は行わない。通常の `sample` と透過工程の `alpha-sample` は同じ処理を通る。適用したbackend・Torch版・MPS上限を各ジョブの `sample-attention.json` / `alpha-sample-attention.json` に記録する。

解像度、入力枚数、モデル、プロンプト、seed、steps、メモリ上限は保持する。保存英訳の再利用指定を既存の実行用スクリプトに追加し、初回失敗と同じ入力で比較できるようにした。英訳に含まれるrequest hashは既存の生成サービスで検証する。

原画と設定画は同じものを使い、別マスク1枚に手と口の離れた2領域を描く。入力枚数は3枚のまま。1056×992上の範囲は、手 `(48,741)–(238,906)`、口 `(271,288)–(374,340)`。指示は、手を握りこぶしにし、開いた口を閉じ、目・眉・視線・冷や汗などを保持するもの。製品の固定プロンプトは変更しない。

実行ジョブ `db5edfd7-3ff1-4878-aa33-194e2e8b3560` は成功。1056×992、英訳を含む311.61秒。原画・設定画は最初のテストとbyte単位で一致する。MPS driver最大12.0584 GiB、MPS allocated最大8.7154 GiB、空き最小13.4856 GiB、swap使用量の範囲0.0078 GiB。

全体・手・口・顔の拡大比較で、手が握りこぶしに変わり、口は閉じて歯と口内が消えたことを確認した。目・眉・視線・髪・冷や汗・衣装・反対の手・脚・配置はよく保たれている。赤い印に相当する出力画素は0。1枚のマスク内に離れた2領域を置くための製品コード追加は不要だった。
