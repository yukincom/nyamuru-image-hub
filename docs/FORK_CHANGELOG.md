# アナログネーム取り込みフォーク変更履歴

本家Nyamuruのアプリ版履歴は [src/content/changelog.md](../src/content/changelog.md) を参照してください。この文書は、本家 `v1.13.2` を基点として本フォークが追加した差分だけを記録します。

## Unreleased — アナログネーム取り込みとコマ編集支援

### 2026-10-31 — 原稿編集とComfyUI人物生成

- 文字・フキダシの編集、レイヤーの追加・移動・選択、生成マスクと履歴中の画像保持を更新。
- 環境設定でComfyUIワークフローを登録・選択できる。人物3枚参照はネームの表情、設定画の外見、3Dのポーズを使い、5候補から選んだ1枚をコマまたはマスクに合わせて透過PNGとして保存する。[登録と操作](../examples/comfyui/README.md#nyamuru_qwen_turbo_3images)
- 登録・送信・候補採用・保存は模擬APIと合成画像で確認。実モデルの出力品質、実3D撮影、スキャナーやCLIP STUDIOとの実機確認は今回の検証に含まない。

### 2026-10-24 — 公開開発先の統一と操作分類器の同梱

- 開発・公開先を `yukincom/nyamuru-image-hub` の1つへ統一。既存公開履歴へ現在の確定済みソースを反映し、旧開発リポジトリの履歴は一括公開しない
- [採用済み操作分類器](../models/nyamuru-voice-v04-seed43/README.md)のtokenizer・provenance・MIT licenseを同梱し、重みを同じリポジトリのReleaseから既存setupで取得できるようにする
- [ModernBERTの改善手順・原記録](ModernBERT/README.md)を公開し、旧モデル・評価・学習入力・Git履歴を同じリポジトリの研究Releaseへ保存
- [LAN利用手順](LAN_EDITING.md)、個人の配置に依存しない開発案内、同梱資産の出典・権利表示を整理
- 描画とレイヤー、3D背景・人体ポーズ・motion、人物資料・作品管理、エージェント・画像生成、LAN編集など、既存の確定済み機能を公開対象に含める
- 実機推論・scanner・外部生成環境・実ブラウザーの確認範囲は、各機能の日付付き記録を参照。今回の公開スナップショット作成だけで、それらすべてを再検証したことにはしない

### 2026-10-17 — Nyamuruの名前とOSS開発方針

- 画面、PWA、単一HTML版、起動メッセージ、利用者向け文書の表示名をNyamuru Image Hubへ復元
- 本家作者とライセンス表記、既存作品の保存キー・形式・内部識別子を維持
- Hermes Agent連携を軸にOSSとして育てる方針を明記
- 公開用リポジトリへのpush、Release、Pages公開は未実施

### アナログネーム取り込み

- 最大10枚の手動画像・連続スキャンを読み込む新規作成フローを追加
- ページごとの手動回転、原画／解析結果サムネイル、見開き順の確認UIを追加
- RT-DETRで検出したコマをテンプレートへ変換せず、編集開始位置として使用
- 文字・顔・身体領域をコマ誤検出の除外に利用
- Baberu OCRの手書き文字候補を編集可能なフキダシへ変換
- 顔・身体を編集可能な人物あたりへ変換
- 読み込み時に上下・左右のコマ間隔と枠線幅を設定し、作品設定へ反映
- macOSイメージキャプチャの起動、連続受信、明示終了、強制終了後の再接続に対応

### コマ編集

- 内枠スナップ、コマ間隔スナップ、コマシンクロを追加
- 四角形・多角形の辺の平行移動と頂点編集を追加
- Shiftドラッグによる水平・垂直軸固定を追加
- 複数コマの選択と、所属する人物・フキダシを保つコマ合体を追加
- 見開き表示と編集画面で、取り込んだコマを直接調整できる操作を追加

### シリーズ人物資料

- 人物を「シリーズ共通」と「この話だけ」に分け、安定ID・人物像・基準頭身・複数のデザイン画像をシリーズ台帳へ保存
- ストーリーOMNYとシリーズ台帳を`meta.document_type`で区別し、ローカル画像の相対パスは台帳だけに保持
- 利用者が「特徴を抽出」を押した資料1枚だけをローカルQwen3-VLへ渡し、抽出結果を編集してから人物設定へ追加
- 抽出結果を追加前から直接編集でき、追加後も再編集欄で修正・削除可能。一般的すぎる人体特徴の候補抑制にも対応
- 画像のSHA-256重複排除、台帳リビジョン競合検出、シリーズ名変更時のID維持、中断した新規画像の整理を追加

### ローカル実行とライセンス

- `127.0.0.1:8787`だけで待ち受けるローカルbridgeを追加
- RT-DETRのONNX推論をNyamuru内へ移し、`manga-babble-maker`への実行時依存を撤去
- `npm run setup:vision`で、利用者の確認後に専用仮想環境・固定版Baberu OCR・検証済みRT-DETRモデルをGit対象外領域へ導入
- モデル重みと一般的なモデル拡張子をGit対象外へ追加
- Baberu OCRとRT-DETRモデルのApache-2.0条件、および外部モデルを同梱しない境界を文書化

### 既知の制限

- 向きは自動判定せず、人間が解析前に正立させます。
- 手書きOCRは文字の書き方と画像品質に左右され、修正を前提とします。
- コマシンクロは実験的です。複雑な分割辺や斜め境界では追従しないことがあります。
- スキャナー起動はmacOS専用です。
- 公開サイトからローカルbridgeへ接続する構成はサポートしません。

## 版番号について

本フォークの正式な配布版番号を決めるまでは、アプリ内の版番号は基点となった本家版を維持します。フォーク版をリリースするときは、本家の版番号と混同しない名前または接尾辞を決め、README・package.json・アプリ内表示を同時に更新します。
