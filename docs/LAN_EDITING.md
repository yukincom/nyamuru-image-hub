# 別のPCからにゃむるを使う

Mac Studioでにゃむるを起動し、別のPCのブラウザーで編集します。作品は編集しているPCへ保存します。

以下では、起動する側を「Mac Studio」、ブラウザーで操作する側を「編集PC」と呼びます。編集PCににゃむるやAIモデルをインストールする必要はありません。

## 1. 2台をつなぐ

2台を同じ家庭内LANにつなぎます。Mac同士なら、LANケーブルで直接つなぐこともできます。

Mac Studioは、編集している間は起動したままにしてください。

## 2. Mac Studioで起動する

文章のAI機能を使う場合は、普段使っている文章AIも起動しておきます。

Mac Studioで、にゃむるのフォルダをターミナルで開いて実行します。

```bash
npm run lan
```

HTTPSの接続先が表示されるまで待ちます。このターミナルは開いたままにしてください。

<details>
<summary>LANケーブルで直結し、接続するアドレスを指定したい場合</summary>

Mac Studioの「システム設定」→「ネットワーク」→「Ethernet」でIPアドレスを確認します。上のコマンドの代わりに、次のように指定して起動します。

```bash
npm run lan -- --host 169.254.224.71
```

数字は例です。Mac StudioのEthernetに表示されている値に置き換えてください。編集PC側のIPアドレスは指定しません。

</details>

## 3. 初めて使う編集PCを準備する

この準備は、編集PCごとに最初の1回だけ行います。登録済みなら「4. 編集PCで開く」へ進んでください。

### Mac Studioから証明書ファイルを渡す

起動画面に表示されたCA証明書ファイル `nyamuru-lan-ca.crt` を、AirDropやUSBメモリーで編集PCへコピーします。これは、編集PCに自分のMac Studioへの接続を認めてもらうためのファイルです。

ファイルを見つけるには、Mac Studioでもう1つターミナルを開き、にゃむるのフォルダで次を実行するとFinderが開きます。

```bash
open .local-vision/lan-tls
```

コピーするのは **`nyamuru-lan-ca.crt` だけ**です。フォルダごと渡す必要はありません。

### 編集PCがMacの場合

1. 編集PCで「キーチェーンアクセス」を開きます。
2. 左側の「ログイン」を選び、受け取った証明書ファイルをウインドウ内へドラッグします。
3. 一覧の「Nyamuru LAN private CA」をダブルクリックします。見当たらなければ、分類を「証明書」にして `Nyamuru` を検索します。
4. 「信頼」を開き、「SSL（Secure Sockets Layer）」を「常に信頼」にします。
5. 証明書のウインドウを閉じます。パスワードを求められたら、編集PCへログインするときのパスワードを入力します。
6. 編集PCのブラウザーを終了して、開き直します。

表示が異なる場合は、Appleの[証明書の追加](https://support.apple.com/ja-jp/guide/keychain-access/kyca2431/mac)と[信頼設定の変更](https://support.apple.com/ja-jp/guide/keychain-access/kyca11871/mac)を参照してください。

<details>
<summary>編集PCがWindowsの場合</summary>

1. `Windows + R` を押し、`certmgr.msc` を入力して開きます。
2. 「信頼されたルート証明機関」の「証明書」を右クリックし、「すべてのタスク」→「インポート」を選びます。
3. 自分のMac Studioから受け取った `nyamuru-lan-ca.crt` を選び、画面の案内に沿って登録します。
4. ブラウザーを終了して、開き直します。

詳しくは[Microsoftの証明書管理の説明](https://learn.microsoft.com/en-us/windows-server/identity/ad-cs/inspect-certificates-manage-certificate-stores)を参照してください。

</details>

## 4. 編集PCで開く

編集PCのブラウザーで、Mac Studioの起動画面に表示された `https://` で始まるアドレスを開きます。接続コードの入力はなく、そのまま編集画面が開きます。

同じLAN内の端末から利用できる、自宅用の接続です。

## 5. 作品を開く・保存する

編集PCではChromeを使います。フォルダーへの読み書きの許可を求められたら、選んだ作品フォルダーへのアクセスを許可してください。

新しい作品は上部の「新規」から作り、編集PC上の作品用フォルダーを選びます。保存済みの作品は上部の「開く」から、その作品フォルダーを選びます。

編集中は、上部の「保存」または `⌘S`（Windowsでは `Ctrl+S`）で、選択した作品フォルダー内の `project.json` へ保存します。構成・作画設定・画像を含むJSONで、単独ファイルのダウンロードではありません。ブラウザー内の自動保存だけに頼らず、終了前に保存してください。

旧名 `作品.nyamuru` だけがあるフォルダーも開けます。開くだけでは変更せず、明示保存で `project.json` を作り、旧ファイルは残します。両方がある場合はJSON内に記録した移行元のハッシュが一致するか、移行記録がなく両方のbyteが同じ場合だけ新しい名前を採用します。旧アプリで旧ファイルを更新した場合など、食い違いを見つけたら読み込み・保存を止めます。新旧両方を保管して内容を確認してください。別の名前の `.nyamuru` は自動選択しません。

保存失敗後も編集中の作品は画面に残ります。初回の失敗で空の `project.json` ができた場合は、旧ファイルを開き直して再保存できます。移行記録は `project.json` の一部なので、それを削除・空にした後の再選択では過去の移行を判別できません。バックアップ時は旧ファイルも含むフォルダー全体を保管してください。競合確認と同一ブラウザーの保存ロックを使いますが、外部アプリやOS障害まで含む新旧2ファイルのtransactionではありません。

Mac Studioの通常版で作った `.nyamuru/project.json` 形式の作品フォルダーは、現在のLAN版では直接開けません。元のMac Studioの画面で開いてください。単独で書き出した `.nyamuru` ファイルも、LAN版の作品フォルダーとしては読み込めません。

## 6. 終了する

1. 編集PCで作品を保存します。
2. 編集PCのにゃむるのタブを閉じます。
3. Mac Studioの、起動したままのターミナルで `Ctrl+C` を押します。

## 次回から

証明書の登録は不要です。Mac Studioで `npm run lan` を実行し、編集PCのブラウザーで表示されたアドレスを開きます。保存した作品フォルダーを開いて続けてください。

## 困ったとき

**証明書の警告が出る**

「3. 初めて使う編集PCを準備する」で、受け取った証明書の登録と信頼設定を確認してください。

**接続コードの画面が出る**

更新前のサーバーが動いている場合があります。Mac Studioの起動ターミナルで `Ctrl+C` を押し、`npm run lan` で起動し直してから、編集PCのページを再読み込みしてください。

**ページが開かない**

Mac Studioでにゃむるが起動していることと、2台の接続を確認してください。以前のアドレスではなく、今回の起動画面に出たアドレスを使います。
