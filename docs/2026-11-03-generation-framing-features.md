# 生成時の撮影範囲と外見特徴（2026-11-03）

## 目的と経路

設定画から確認した特徴一覧は登場人物の正本として残す。生成時の派生文だけを人物の撮影範囲で絞り、顔アップの指示に全身衣装・靴・全身体型が混ざることを防ぐ。設定画そのものは切り直さず、image2として送る。

既存の `buildQwenGenerationPlan` と `qwenPlanForWorkflow` を使う。生成planは特徴のカテゴリと原文のスナップショットを保持し、現在の撮影範囲から派生文を作る。3D編集で全身から顔へ変えた場合も同じスナップショットから選別し直すため、全身へ戻せば衣装や靴の指定も戻る。元の `recognition`、特徴編集欄、Undo、作品保存の経路は変えない。

撮影範囲の固定英文は `src/content/figure-framing.json` で共有し、Pythonの既存英訳処理と人物3枚参照の両方で使う。新しい推論・通信経路は追加しない。

## 生成用の選別

| 撮影範囲 | 自動指示へ渡す特徴 |
|---|---|
| ロング・全身 | すべての採用特徴 |
| 膝上 | 足先・靴・ふくらはぎ・床丈などを除外 |
| 腰上 | 脚・足先・裾を除外。シルエットは首・肩・胸・胴などの上半身を明示したものに限定 |
| 胸上 | 腰上の除外に加え、腰・手・前腕などを除外 |
| 肩上 | 全体のシルエットを除外。衣装は首・襟などの単独説明に限定 |
| 顔・顔の一部 | 髪・顔と、頭部と明記された装飾に限定。首・胴・手足・裾などを含む句は除外 |
| 手・足 | 対応部位を明示し、ほかの部位を含まない句に限定 |
| 任意の部分 | 対象部位が特定できないため、自動の特徴列挙を外し画像資料を使う |

英語・日本語の部位語と特徴カテゴリによる保守的な選別であり、VLMによる意味判定や画像の可視領域解析ではない。範囲内と範囲外が一つの句に混ざっていたら、その句全体を除外し、原文を分解・書き換えない。説明不足はimage2の設定画で補う。手動で編集した生成文は再選別せず、送信文として優先する。

## 顔アップで追加する指示

```text
Framing (from <image1>): close-up of the face.
Match the crop, subject scale, camera angle and visible body region of <image1>. Keep its cut edges; draw only the body parts visible there. Use <image2> for the appearance of those visible parts. Render one view of one character.
```

たとえば「黒いカチューシャ、白いVネックドレス、黒タイツ、黒い靴」の特徴を持つ検証用人物では、顔アップの `Observed features` はカチューシャだけになる。ドレス・タイツ・靴は元の一覧と保存データに残り、全身では再び生成文に入る。
