# 文字ツールの情報タブ

## 目的と配置

文字ツールを「文字」「ふきだし」「情報」の3タブにする。コマ情報の吹き出しカードを、順序・幅・フィールド配置を保って情報タブへ移す。カードの話者、しっぽ、結合先、追加・削除、シナリオ候補の確認も移動する。

## 既存経路と責任

- 作品の正本は既存document。PanelInspector / PageOverlayInspectorの更新処理、ロック検査、Appのmutate、Undo/Redo、明示保存を再利用する。
- BubbleInfoPortalは表示先のみを移す。情報タブ専用の作品state・保存経路・更新APIは追加しない。
- 道具・対象選択・タブの開閉は作品編集ではない。情報タブの選択で文字ツールを起動せず、吹き出しやコマを選び替えてもタブを保持する。
- コマ内とページ前景は既存のInspector切替に従う。同じカードをコマ情報へ重複表示しない。
- シナリオから吹き出し候補を確認する入口は情報タブへつなぐ。

## 合格条件

- 3タブの切替、選択ツールの維持、吹き出し・コマ・ページ前景の選び替え。
- カード順序と幅、話者→しっぽ→結合先の配置、ロック、追加・削除の維持。
- 各値の対象限定更新、Undo/Redo、保存・再読込。
- コマ情報の吹き出しカード撤去と、情報タブ内だけの選択追従スクロール。
