# 人物生成の外見情報

2026-11-02。「キャラクターの特徴を確認・再編集」に登録された装飾・髪型・顔・シルエット・衣装の `recognition.*.observed` を、人物生成の外見情報として使う。

「画像生成用ビジュアルプロンプト」の入力欄は撤去し、その保存値は生成指示へ加えない。外見は既存の `buildQwenGenerationPlan` → `characterAppearance` → `qwenPlanForWorkflow` の経路を使い、3枚参照の `Character & Design (from <image2>)` に入る。名前が同じでも人物IDで対象を選び、一覧の手動編集・削除は次に開く生成画面へ反映する。

各項目は前後の空白と完全重複を整理して1回ずつ添える。追加の要約や項目数・文章長による切り捨ては行わない。抽出候補は「特徴を追加」で採用した内容を使い、未採用候補・推測欄は使わない。生成画面のプロンプトを手動編集した場合は、その送信値を使う。

通常画面で確認した小雪の一覧は15項目・英語91語・600文字。まずこの内容をそのまま使う。量による画質への影響は実生成で確認する。

関連Node54件成功。本人の特徴と作品画風の送信、旧自由文・別人・推測項目の除外、編集・削除後の反映、image1/2/3の順序を検査した。推論APIは模擬で、実モデルの画質は未確認。

既存の3D検証設定と人物生成の実ダイアログでも、合成ネーム・設定画を使い、ヘアバンド・衣装の特徴がimage2用初期文と手動追記後の送信内容に残ることを確認した。3枚の画像役割と、保存・再読込後の指示も検査。変更した3ファイルの型診断は0件。
