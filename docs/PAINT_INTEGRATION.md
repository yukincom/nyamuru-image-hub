# ページ上のペイント

左の「ペン」または右の「レイヤー」バーからペイントモードへ入る。ページ全体・見開き・周囲のコマを表示したまま、選んだあたりに描く。

- 背景、人物・小道具ごと、吹き出しごとに独立したグループを自動作成する。グループ内には描画レイヤーを追加できる。コマそのものを描画レイヤーにはしない。
- ページ一覧の右にペンツール、キャンバスの右にレイヤー、その外側にコマ情報を配置する。それぞれの境界バーで開閉できる。
- ペン、消しゴム、直線、四角、楕円はアイコンで選ぶ。Shiftを押しながら描くと、直線は水平／垂直、楕円は正円、四角は正方形になる。黒・白と筆圧による太さに対応する。手ぶれ補正は環境設定の「作画方法」に置き、初期値は0。
- レイヤーはコマ配下の人物名・背景・吹き出しのフォルダーに分け、上の行ほど手前に重なる順で表示する。サムネイル、目のアイコン、固定、不透明度、通常／乗算、並べ替え、複製、削除を備える。名称はダブルクリックで編集する。「画像を読み込む」アイコンからPNG/JPEGを画像レイヤーとして追加できる。同じ人物・背景フォルダー内の描画レイヤーは掴んで上下へ移動する。濃度はフォルダー内の選択レイヤーに適用する。
- 対象の右クリックメニューに「サイズコピー」「画像を読み込む」「あたり画像表示」「生成」「この画像を参照して生成する」をまとめる。レイヤーのフォルダーや行からも同じ対象を操作できる。画像読み込みは対象グループの内容を置き換え、Undoで戻せる。元のあたり情報は保持する。
- 「あたり画像表示」は対象ごとに切り替える。人物・背景の情報欄にもチェックボックスを置き、他の人物や背景の状態を変えない。ペイント中は元のあたりを下敷きとして表示する。あたりは合成PNGに含めない。
- 矢印の「選択・移動」に切り替えると線を作品内に保持し、配置枠の移動・拡縮へ戻る。戻す・やり直すは上部にまとめ、描画中は30操作のペイント履歴、それ以外は作品の履歴を使う。上部の「保存」と⌘/Ctrl+Sは、描画中の線を確定し、編集可能なレイヤー・合成PNG・原本を作品フォルダへまとめて保存する。保存に失敗しても描画内容は画面内に残る。⌘/Ctrl+Z、Shift+⌘/Ctrl+Z、⌘/Ctrl+Y、⌘/Ctrl+Sに対応する。描画中のボタンの色は変えない。

短い連続線も1筆ずつ保持する。ペン入力が途中で中断した場合やウィンドウのフォーカスが外れた場合は、そこまでの線を確定する。描画中のEscapeだけは現在の1筆を取り消す。ペンが接触している間はタッチやホイールによるページの移動・ズームを抑え、描画位置を保つ。

## 描画範囲

実線は描画キャンバス、外側の点線は「はみ出し枠」。はみ出し枠内からペンを下ろし、実線の内側へ連続して線を引ける。入力用のはみ出し枠は周囲5mm。筆跡は外側の座標も保持し、合成PNGは描画キャンバスで切り取る。コマに所属する人物・背景の表示には、そのコマのクリップも適用する。

配置枠を手動で拡縮し、環境設定の「作画方法」で描画範囲を設定する。コマのスナップ・シンクロと分割・合体は、コマ情報の「コマ コントロール」を下へ展開して操作する。

- **ぬりたし**：環境設定で四辺共通のpx数を指定する。初期値は200px。描画を開く際に不足分だけを追加し、再度開いても重ねて追加しない。設定値を小さくしても既存の線を切り取らない。既存の絵、線幅、元のあたりのページ上の位置・大きさを保って描画範囲を広げる。コマの形は変えない。

範囲拡大は現在の配置と画素数の対応を使うため、拡大・縮小の後でも絵の大きさを保つ。元画像のcropや過去のレイヤーclipは維持する。clipのあるレイヤーで追加作画する場合は新しい線画レイヤーを作り、消しゴムは選択レイヤーに適用する。

各ツールにカーソルを約1秒置くと、操作方法を表示する。キーボードでフォーカスした場合も表示し、Escapeで説明を閉じる。選択ボタンは濃い茶色、選択中は緑色と明るい枠、押している間は橙色で示す。

## ベクター作画

「ベクターレイヤー追加」からベジェ曲線を描く。四角・楕円・直線もベクターとして作成し、ラスターのレイヤーを選んでいる場合はベクターレイヤーを追加する。

- ペン先アイコンの三角から、ベジェペン・アンカーポイント追加・アンカーポイント削除・アンカーポイントを選ぶ。追加は線を分割し、削除は点を除いて残りをつなぐ。「<」アイコンのアンカーポイントは点のクリックで角、ドラッグで滑らかな接線ハンドルを作り、ハンドルを片側ずつ動かせる。
- ペン先アイコンはベジェペン。クリックで角、押したままドラッグで接線ハンドルを作る。描画途中で置いた点も、その位置をドラッグしてハンドルを引き直せる。始点をクリックして閉じ、始点をドラッグするとハンドルを作りながら閉じる。描画中の最後の点をクリックすると出る側のハンドルだけを取り除き、直前の曲線を保ったまま次を直線にできる。開いたパスの端をクリックすれば続けて描ける。
- 描画を続けながら点を変換する場合は、ベジェペンのままOption/Altを押す。点をクリックすると角にし、ハンドルをドラッグすると片側だけを動かす。キーを離せば同じパスの続きを描ける。
- 開いた線を終えるには、⌘/Ctrlを押して空白をクリックするか、Esc・Enter・⌘/Ctrl+Shift+Aを使う。別ツールを明示的に選んだ場合も描画を終了する。Pに戻って空白をクリックすれば別のパスを開始し、既存の端をクリックすればその線を再開する。
- 「パス選択」の矢印でパスを選択・移動する。Shiftクリックまたは範囲ドラッグで複数選択、⌘/Ctrl+Aで選択レイヤーの全パスを選ぶ。
- 「ダイレクト選択」の矢印でアンカーとハンドルを移動する。Option/Altでハンドルを独立させる。ベジェペンで線上をクリックするとアンカーを追加し、Option/Altクリックで角へ切り替える。「ダイレクト選択」で点を選びDeleteでその点を消す。
- ラスターのペンは筆圧で太さを変える。ベクターレイヤーのフリーハンドは曲線へ変換し、太さは「線幅」と「線幅形状」で指定する。「ラスター」の色・太さと「ベクター」の色・線幅、消しゴムの太さはそれぞれ別に保持する。
- 「ベクター」で線端・角・破線・始点と終点の矢印・線幅形状を見本アイコンから選ぶ。線端・角・線の位置の見本には、細い実線のパスと四角いアンカーポイントを重ねて示す。線の内側／外側指定は閉じたパスに適用する。黒・白・塗りなしに絞る。
- 「整列・分布」で端・中心の整列、端・中心の均等分布、等間隔・指定間隔の分布を行う。基準は選択範囲、最初に選んだオブジェクト、描画範囲。最初の選択を基準にした場合、そのオブジェクトを固定する。
- ベクターレイヤーの消しゴムは、触れた部分・交点まで・線全体を選ぶ。交点判定は選択レイヤー内のパスを参照する。曲線を切ったあとも残りのアンカーとハンドルを保持する。
- アンチエイリアスはレイヤーごとに、なし・弱・中・強の境界濃度を選ぶ。ぼかしは使わない。読み込んだ画像の画素は変更しない。

レイヤー内のベクター形状、ハンドル、線設定とアンチエイリアスを保存し、合成PNGをページ表示・生成参照に使う。一般的なIllustrator文書全体の互換実装ではなく、ニャムルのあたり内で描くベクター作画機能であり、AI形式の入出力は行わない。

幾何処理は[Paper.js 0.12.18](https://github.com/paperjs/paper.js/tree/v0.12.18)を利用し、MITライセンス本文を同梱する。ペン操作は[Adobeのベジェ曲線の説明](https://www.adobe.com/jp/learn/illustrator/web/draw-edit-curves)、分布は[Adobeの整列・分布](https://helpx.adobe.com/illustrator/desktop/manage-objects/arrange-objects/align-and-distribute-objects.html)を参照する。

描画中の変換と終了は[Adobeのペン操作チュートリアル](https://www.adobe.com/learn/illustrator/web/use-pen-tool)、[パスの終了方法](https://helpx.adobe.com/illustrator/using/tool-techniques/pen-tool.html)、別ツール選択による終了は[Illustrator公式リファレンス「Finish drawing a path」](https://helpx.adobe.com/pdf/illustrator_reference.pdf)を参照する。Enterでの終了は本アプリの補助操作。

ショートカットは選択 V、ダイレクト選択 A、ベジェペン P、アンカーポイント追加 ＋、削除 −、アンカーポイント Shift+C、長方形 M、楕円 L。文字入力・日本語変換・描画中にはツールを切り替えない。保存 ⌘/Ctrl+S、取り消し ⌘/Ctrl+Z、やり直し ⌘/Ctrl+Shift+Z。

## 原情報と保存

`Figure`の人物参照ID、アクション、名前、アナログ原画参照と検出領域を残し、`Figure.artwork`へ合成PNGと編集可能な`paint`を保存する。背景は`Panel.background_images`、吹き出しは`Bubble.paint_overlay`へ保存する。吹き出しの本文、話者、形、しっぽ、OCR対応は元データとして保持する。ページ表示と同じ文字組み・しっぽ・結合形状の上で描画する。

`paint` v1は寸法、DPI、下から上へ並ぶレイヤーと筆跡を保持する。任意の`referenceFrame`は元のあたりの領域を画素座標で記録する。余白追加時は筆跡・画像レイヤー・clip・元のあたりを同じ画素量だけ移動する。読み込んだ画像は原本asset IDとcropで参照し、原本のバイト列を書き換えない。背景の描画キャンバスはコマと独立したbboxを持ち、コマ分割・結合後の画像やレイヤーも再編集できる。

あたり表示やペイントデータを含めないOMNY出力では、元のあたりの領域からbboxを復元する。作品フォルダの保存には合成PNGだけでなく、レイヤー内だけで使う原本も含める。ブラウザ保存と作品フォルダからの再読込でレイヤーを再編集できる。手描き作業にLLMや外部サービスは使わない。

プレビューは選択グループの長辺1536px、他グループ768pxを上限にする。筆跡更新と配置更新のコンテキストを分け、ペン移動ごとにページ全体の文字組みを再描画しない。Undoは筆跡データを保持する。PNG合成時は原寸キャンバス2枚を順に利用する。3000×4000pxならRGBA領域は2枚で約96MB（ブラウザ内部の複製、原本デコード、PNG圧縮領域を除く計算値）。

## 検証範囲

自動検証は、自動グループ分け、元情報と原本を含む保存／復元、範囲拡大の前後での描画位置・線幅、crop後の元あたりの位置、背景とコマの独立性、範囲外からの座標変換、連続線の保持、短い払いの終点、Shiftによる図形の制約、対象ごとのあたり表示、あたり復元／OMNY出力、壊れた参照の保存拒否、消しゴムの合成先、プレビューキャッシュを対象とする。

ペンタブの実際の筆圧、描き心地、作品フォルダ選択からの往復は実機で確認する。レイヤー付きPSD/ORAの入出力、選択範囲や塗りつぶしは未実装。
