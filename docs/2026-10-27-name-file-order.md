# ネーム画像のファイル名順

- 利用者の確認により、新規作成の手動画像読み込み順を点検した。選択ダイアログから返る順をそのまま使っており、ファイル名順を保証していなかった。
- 既存の `chooseNewLayoutImages` でファイル名の数字を考慮して並べる。`スキャン 00 → 01 → 02 → 03`、`page1 → page2 → page10` の順になる。
- ローカルとブラウザーの画像選択は同じ処理へ入る。プレビュー・解析・ページ生成はその配列順を使う。スキャナーの受信処理は変更していない。
- 実handlerの対象試験1件で、逆順・数字の桁数が異なる入力を確認した。全件テスト・ビルドは実行していない。
- 修正後も利用者のページ設定画面が維持されていることを確認した。実ネームの選択・解析は利用者の操作待ち。
