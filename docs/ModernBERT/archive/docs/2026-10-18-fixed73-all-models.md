## 再現

元の受領成果物を `artifacts/` に保持した状態で、リポジトリ内から固定依存のPythonを使う。`--output` には未作成の保存先を指定し、既存結果を上書きしない。

```sh
python compare_saved_models.py run --output artifacts/fixed73-all-models-rerun
python compare_saved_models.py verify --output artifacts/fixed73-all-models-rerun
```

この比較では学習条件の違いを含む保存済みモデルの性能を比べた。v0.3からv0.4への改善が、追加データだけによる効果かを分離する実験ではない。固定73問での比較は成立しており、未使用の実利用発話に対する精度は別途確認が必要。
