## モデルと学習

[SB IntuitionsのModernBERT-Ja 30M](https://huggingface.co/sbintuitions/modernbert-ja-30m)をベースとして、[TransformersのModernBERT分類実装](https://huggingface.co/docs/transformers/model_doc/modernbert)で19分類のヘッドを新規学習する。以前の5分類重みからの継続学習ではない。

|---|---|
| ベースモデル | sbintuitions/modernbert-ja-30m |
| revision | 8cb03f54cb9e30e72459e5f1cedc6d89c7d8dcb5 |
| seed | 42 / 43 / 44 |
| 学習率 | 2e-5 / 5e-5（計6試行） |
| epoch | 各10 |
| batch | 16 |
| 入力上限 | 128 token、切り詰めなし、動的padding |
| 計算 | CUDA、float32、SDPA、TF32無効 |
| 更新 | 全パラメータ、AdamW、weight decay 0.01 |
| 学習率変化 | linear、warmup 0 |
| Python | 3.11.14 |
| 主な依存 | torch 2.14.1 / transformers 5.19.0。全依存はrequirements-train.txt |

実トークナイザーで全316件を確認。3〜16 tokenで128以内、切り詰め0件。これはテキスト処理の検査であり、モデル推論ではない。

各試行でdev macro-F1最大のepochを保存。同値ならdev lossが低いもの、早いepoch、先の試行順。3 seedの最良dev成績を平均して共通学習率を1つ選び、選ばれた3モデルをすべて保存する。testを見てseedや学習率を選ばない。

選択用macro-F1は従来集計との整合のため19ラベル固定分母・ゼロ除算0とする。devに存在するラベル集合が固定なので、存在する12ラベルだけのmacro-F1と候補順位は同一。利用者向け結果では、実際に例がある分類だけのmacro-F1と全19分類のsupport表を出す。欠落分類の集計上の0を、測定した性能0%とは解釈しない。
