# v0.5.1：二視点学習のNaN修正

2026-10-18。v0.5のColab実行で、baselineの6試行終了後、dropout_2viewのseed42・学習率2e-5が4epoch目に停止した。ログはgrad_norm=nan、eval_loss=nan、その後ValueError: Out of range float values are not JSON compliant。Colabのusage上限を示すエラーではない。

## 再現した不具合と修正

旧実装は、両側に勾配を流す対称KLへsoftmax確率をtargetとして渡していた。float32でlogits=[100,-100,0]と[90,-90,0]を使うと、forwardのCE・KLは有限でも両側の勾配がNaNになる。係数0でKLを掛けても、非有限な逆伝播を防げない。この欠陥はローカルで再現した。

PyTorchの[KLDivLoss公式仕様](https://docs.pytorch.org/docs/2.14/generated/torch.nn.KLDivLoss.html)に従い、双方のlog_softmaxをlog_target=Trueで渡す。クラス方向の和・例方向の平均・双方向の平均は同じで、対称KLの定義と両側勾配を保つ。確率のclampやdetachで目的関数を変えない。係数0の対照条件ではCEを直接返し、KLは診断値としてのみ記録する。

非有限dev logits・指標は明示的なFloatingPointErrorで停止し、JSONへのNaN書込みや不正なcheckpoint選択を行わない。Colabの親プロセス出力をcomparison.logに保存し、異常終了時は子のTracebackも表示する。

## 比較条件と証拠の範囲

train/devを含む7 splitの1934件、19分類、モデルrevision、3 seed、2学習率、10epoch、二視点dropoutとR-Dropの比較条件はv0.5と同じ。新しいプロンプト・発話・ラベルはない。全条件のdev確定後に方法を固定し、その後で既読testの回帰評価を行う。

元のv0.5入力ZIP・コード・失敗したColab出力は保持し、修正版は別のv0.5.1として保存する。Colabの作業先も/content/nyamuru-voice-v051-20261018へ分ける。失敗したrunへ途中から学習を継ぎ足すことはしない。

極端な確率での有限勾配、float64参照との損失・勾配一致、係数0でKL経路を除外すること、非有限dev拒否、内部例外のログ伝達を回帰テストへ追加した。小さなランダム初期値だけの旧テストでは、実学習で予測が尖った後のunderflowを捉えられなかった。

保存済み3epoch checkpointについて、T4上で固定seedの81 batchを検査した範囲では旧KLの勾配NaNを再現しなかった。4epoch目の実際の失敗batchを保存していないため、この検査だけで発生箇所を断定しない。修正版のT4診断とローカルの配布検証結果は、同じディレクトリのpreparation-v051-verification.jsonへ別途記録する。診断の数試行は正式な18試行比較や精度改善の証拠には数えない。
