MASSIVE日本語の選定原文、漫画編集向けの派生合成例、否定・Undo/Redo・複数操作の追加例を使う版です。本文textだけを分類し、slotsや注釈、画面情報は入力しません。件数と出典はREADME.mdとdata-report.jsonで確認できます。

1. 「ランタイム」→「ランタイムのタイプを変更」でGPU（T4等）を選ぶ。
2. 「ランタイム」→「すべてのセルを実行」。最初の入力欄で **nyamuru-voice-v03-inputs.zip** を選ぶ。

4. **nyamuru-voice-v03-colab-results.zip** を保存して、このチャットへ渡す。3モデルと結果の保存を確認したらGPUを解放する。

3 seed（42/43/44）×2学習率（2e-5/5e-5）、10 epoch、batch16、128 token、float32/SDPA。入力の切り詰めは行いません。各試行のepoch、共通の学習率、主評価のseedを新しいdevだけで選び、確定後に新testを評価します。95%目標の判定には、この主評価モデルの新test正解率を使います。
