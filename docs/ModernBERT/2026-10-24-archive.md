## 復元

Release assetsを同じ空フォルダへダウンロードして、まずチェックサムを検証します。続いて空の`restored/`へ5つのアーカイブを展開します。ファイルを連結する分割形式ではありません。

```sh
shasum -a 256 -c SHA256SUMS
mkdir restored
for part in source-evaluation-records-01.tar.gz model-checkpoints-01.tar.gz model-checkpoints-02.tar.gz model-checkpoints-03.tar.gz original-transfer-zips-01.tar.gz; do
  tar -xzf "$part" -C restored
done
```

`restored/colab-nyamuru-voice-2026-10-17/`に元の相対配置が復元されます。履歴も必要なら、別の空フォルダへbundleをcloneします。

```sh
git clone nyamuru-modernbert-source-history.bundle history
git -C history rev-parse HEAD
```

履歴cloneの上へ研究ファイルを重ねれば、元Gitが追跡していなかった成果物も揃います。cloneだけでは重みや無視ファイルは復元されません。到達不能blob2個は通常の履歴に含まれないため、必要な場合だけ`UNREACHABLE_GIT_OBJECTS.json`のBase64を復号します。Git object IDも記録しています。

## 除外と記録上の注意

研究外の`.DS_Store`、Pythonの`__pycache__`、`.ruff_cache`、ローカルGit設定・hook等は除外しました。履歴はbundle、到達不能blobは別JSONで保持しています。除外path・件数・bytesは`MANIFEST.json`に列挙しています。元フォルダにsymlink、私物の漫画画像、音声・動画はありませんでした。元テキストの合成例と利用者提供の操作例8件は研究入力として保持しています。

Git履歴・現存テキスト・ZIP内テキスト・公開データtar.gzの各memberを既知の認証情報パターンで走査し、該当はありませんでした。これは任意の機密情報が存在しないことの証明ではありません。記録内の過去のローカルpathやGit作者情報は保存原文に含まれます。

保存時点の研究フォルダには、過去に受領した学習結果ZIPそのものはありませんでした。展開された結果、入力hash、保存予測、18重みは現存しており、全て保存しました。v0.1は学習準備のみ、v0.5のNaN試行は正式比較外という当時の区別を保っています。
