# ニャムル操作分類器の改善記録

採用モデルは **通常学習 v0.4 の seed43**（2026-10-20決定）。v0.5.1 baseline の同じseedと同一重みです。[モデルと導入手順](../../models/nyamuru-voice-v04-seed43/README.md) · [当時の採用記録](archive/docs/2026-10-20-seed43-adoption.md)

| 評価 | 採用seed43の結果 | 数値の条件 |
| --- | ---: | --- |
| 固定73問 | 60/73（82.19%） | 全19分類を含む、閲覧済みの合成回帰評価 |
| 短い日常112問 | 110/112（98.21%） | 14操作分類を各8問。確認・推論・複数操作・対象外・非命令は正解例に含まない |
| 日常112問のうち学習文と正規化一致しない97問 | 95/97（97.94%） | 字面の非一致を確認した部分集合。意味的独立性の保証ではない |

いずれもテキストからの分類評価です。実利用頻度、音声認識、引数解決、アプリ実行を含む精度ではありません。元のdevによる事前選択はseed44であり、その記録と、73問の比較を経たseed43の採用判断を分けて保存しています。

改善は、19分類の契約固定 → family単位の分割 → 境界例と公開資料の選定 → 単一・複数操作の対照例追加 → 学習方法の統制比較 → 同じ評価での比較、の順で進めました。同じ73問での3seed平均はv0.2の70.78%、v0.3の74.89%、v0.4の81.28%。二視点dropoutとR-Dropの追加による改善は確認できませんでした。
