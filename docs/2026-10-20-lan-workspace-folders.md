# 編集PCのフォルダーで作品を保存・再開する

LAN接続時は、ブラウザーを開いているPCのフォルダーを選び、資料の読み込みと作品の保存を行う。モデル処理はMac Studioへ依頼する。

## 使い方

1. 新規作成で、シリーズまたは読み切りを選ぶ。
2. シリーズ共通の資料がある場合は「シリーズ」の保存先を選ぶ。人物設定などの候補を確認し、「選んだ件数を反映」を押す。
3. 「今回のエピソード」の保存先を選ぶ。シリーズフォルダーを指定した場合は、その中のエピソード用フォルダーを選ぶ。
4. フォルダー内の台本が表示されたら「この資料を反映」を押す。別の資料は「変更」で選べる。
5. 作品を作成して「保存」を押す。選択したエピソードフォルダーの `作品.nyamuru` に保存する。
6. 続きを編集するときは「開く」で作品フォルダーを選ぶ。

保存先を変える場合は、右上の歯車から「環境設定」→「データ管理」→「保存先フォルダを変更」を使う。「OMNY書き出し」もデータ管理に置く。OMNYには作品の構成・セリフを含み、画像原本や作画設定は含まない。

フォルダー選択には File System Access API 対応のChrome等が必要。新規作成にはエピソードフォルダーの選択が必須。非対応ブラウザー・権限拒否・キャンセルでは操作を中止し、単独ファイルの読込・保存へ切り替えない。ブラウザーが再度アクセス許可を求めた場合は、選んだフォルダーへの許可が必要。

## 保存内容と境界

- フォルダー内の保存形式として `.nyamuru` を使用する。作品本文、現在の作品で使う画像原本、人物の資料画像、作画設定、3D舞台原本を含む。シリーズ全作品をまとめたバックアップではない。
- フォルダーへのアクセス情報は編集PCのブラウザーに保存し、サーバーへ渡さない。読み込んだ資料からモデルを使う操作を実行した場合は、その操作に必要な内容をMac Studioへ送る。
- フォルダー内に `name_data`、`draft_data`、`manuscript_data`、`export_data` を準備する。作品の保存実体はフォルダー直下の `.nyamuru` ファイル。
- 読込・保存対象は `作品.nyamuru` に固定する。別名ファイルの探索や、記憶した別名への復帰は行わない。単独ファイルを開く・書き出すUIと処理は持たない。
- ファイルが他の画面・アプリで更新されていた場合は上書きを中止する。保存先変更のキャンセルや書き込み失敗では、保存成功と表示しない。
- Mac Studioの通常起動版は `.nyamuru/project.json` と資産フォルダーを使う。この形式の作品は通常起動版で開く。LAN版との相互変換・移行用の単独書き出し経路は設けていない。
- 作画用ラフの制作台帳や原文照合レポートのサーバー保存機能は、ブラウザーフォルダーへ接続しない。通常の作品保存とは別の機能。

## 検証

実ブラウザーの専用画面 `tests/browserWorkspace.browser.html` を使用。選択ダイアログのみを検証フォルダーに置き換え、フォルダー・ファイルの読み書きとアクセス情報の保存にはブラウザーの実装を使用した。実作品やモデル処理サービスは使用していない。

- 新規作成でシリーズフォルダーを選び、人物設定を検出して反映。
- エピソードフォルダー内の台本から、題名・話数・舞台設定を読み込み、作品を作成して保存。
- 画像原本1件・人物資料画像1件を含む `作品.nyamuru` の保存実体を確認。
- 画像キャッシュと編集中の作品データを消して白紙起動し、フォルダーから作品と両画像を復元。
- ページ再読み込み後も同じフォルダーへ保存できることを確認。
- 自動テストで、外部更新・新規ファイル作成との競合、書込失敗、権限拒否、キャンセル、シリーズ外の資料選択拒否、フォルダー未選択の拒否、別名ファイルの拒否、保存後のシリーズID維持を確認。

編集先Macの実際のフォルダー選択ダイアログとアクセス許可の復帰は未確認。画面確認はこのMacのブラウザー内の検証専用フォルダーで実施した。

2026-10-23の画面・保存経路の整理と検証結果は [設定・フォルダー操作の仕様](2026-10-23-folder-entry-ui.md) を参照。
