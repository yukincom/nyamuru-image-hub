# 2026-10-24 文字ツール・環境設定・背景3D導線

## 変更した操作

- ネーム画面の `T` は通常文字ツールになった。選択した時点で12.0pt・縦書きの編集可能な文字を作り、コマ内または紙面の空き場所をクリックするとその位置へ移せる。
- 既存の吹き出しを `T` でクリックすると、吹き出し中央を基準に文字を編集する。
- 吹き出し素材を通常文字へドラッグすると、文字・書体・太さをネイティブ吹き出しへ移し、変換時だけ文字量と約20ptの余白に合わせて外形を調整する。変換後のサイズは自動追従しない。
- 空のネイティブ吹き出しを通常文字へ重ねた場合も同じ変換を行う。ペイント画像や任意の白い描画パスは誤判定を避けるため対象外。
- アプリ起動時にブラウザの Local Font Access API からPC内フォント名を確認する。前回保存した一覧と異なる場合だけ分類結果を更新し、同じ場合は保存済み一覧をそのまま使う。起動時に権限が得られなかった場合は、選択中文字の書体一覧を開いたユーザー操作内で再試行する。未対応・拒否時も内蔵候補で編集を継続できる。
- 選択文字の書体と太さを同じ「フォント」枠にまとめ、長いPC書体名も横幅からはみ出さないようにした。サイズは0.1pt単位で入力・保持する。
- 通常の選択・移動中に吹き出しをクリックしても文字設定は開かない。`T` ツールを選んだ時だけ、文字設定を左側の描画ツール内（太さとアンチエイリアスの間）に表示するため、紙面上で吹き出しの位置を微調整する領域を塞がない。

## 画像書き出し

- レイヤー欄の画像書き出し形式で `PNG` または `PSD` を選べる。
- 人物・背景・吹き出しを選択中は、その対象の統合画像を書き出す。何も選択していない場合と、画像ではない通常文字・配置画像を選択中の場合は、ボタンを「ページ全体」に切り替える。
- ページ全体は印刷設定の用紙mmとdpiを画素寸法へ変換し、画面の選択枠・あたり表示・操作ガイドを含めずに合成する。生成済みのページ／コマ画像は通常の紙面内容として含めるが、AIへ再入力する生成用合成では従来どおり除外する。
- PSDはPhotoshop PSD v1の8bit RGBまたはグレースケールの統合画像で、解像度情報を保持する。レイヤー構造の移送ではなく、CLIP STUDIO PAINT／Photoshopへ完成紙面を渡す用途とする。
- 異常な用紙値と1億画素を超える出力を拒否し、透過部分は白い紙へ合成する。

## 環境設定の整理

- `テキスト` タブを廃止した。吹き出し線幅は `T` のサブメニューへ移し、数値欄の直後に `mm` を表示する。紙面上の書体変更は選択中の吹き出しまたは通常文字だけに適用する。
- 新しく追加する文字の「作品の基本書体」は `環境設定` → `レイアウト` に置いた。基本書体を変更すると、配置済みで書体を省略していた文字へ変更前の基本書体を明示保存してから既定値だけを更新するため、既存の見開き・ページ全体の文字は変わらない。
- フォント一覧の各項目は5列を保ったまま高さ40pxへ圧縮し、読込件数の状態文は表示しない。意味名 `アンチック体` は、この端末へ導入済みの `I-OTFアンチックStd B` / `I-OTFアンチックStd`（英字family aliasを含む）を最優先で描画する。
- 旧 `作画方法` は `手描き・編集`、`生成ルール`、`OMAY` に分けた。
- 完成画像のカラーとdpiは `レイアウト`、生成画像用の見出し・作者名・強調寸法は `生成ルール` に置いた。
- OMAY（生成ルールの受け渡し）とOMNY（作品データの書き出し）が別形式であることを画面上に明記した。
- 保存キーとOMNY/OMAY内のデータ位置は変更していない。

## 背景3Dモデル

- 既存の `舞台設定` → `背景作画資料` → 各背景カードにあるGLB/FBX登録経路を明示した。
- 読み込んだ原本はアプリ管理領域へコピーされるため、元ファイルが別ディレクトリにあっても、後から移動・取り外ししても紐づけは維持される。
- `シリーズ共通` の背景を `舞台設定を保存` すると、同じシリーズの別エピソードで同じ管理コピーを再利用する。
- 新規作成の舞台入力にも、作成後の登録場所を案内する表示を追加した。保存形式や別の背景3Dバックエンドは増やしていない。

## 通常文字の始点と文字サイズ（2026-10-25）

- コマ内・ページ前景の通常文字は、範囲テキストではなくクリック位置を始点にする点文字として扱う。特にコマ枠外では、縦書きは始点を右上とし、改行で列が左へ増える。横書きは始点を左上とし、改行で行が下へ増える。
