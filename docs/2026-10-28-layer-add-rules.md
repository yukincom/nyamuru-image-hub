## 既存経路と変更責任

- 追加ボタンは `PageLayerPalette` / `PaintLayerControls` → `layerTransition` / `PaintEditor.layerAction` → 既存の履歴・`applyPaint`・作品フォルダー保存へ接続する。ラスターボタンとベクターボタンに分散していた直接追加を `layerAction` へ集約する。
