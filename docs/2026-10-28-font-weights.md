# 書体ごとの実ウェイト

2026-10-28。日本語書体名の利用者確認後、`c9bade8` を回復点として着手。

- 既存のLocal Font Accessと名称テーブル読取を拡張し、書体内の各faceから太さの名称と値を収集する。W名は拡張ファミリーのname ID 17、通常のファミリーはID 2を使い、日本語名を優先する。
- 数値はOS/2の `usWeightClass` を使う。ヒラギノW2の250などを100刻みに丸めない。名前付き可変ウェイトも取得し、太さ以外の軸が異なる候補を混ぜない。斜体ではない標準幅の候補を優先する。
- 文字パレットには収録済みの候補だけを表示する。1種類しかない書体と取得できない書体は太さ欄を無効にする。汎用の「細め／標準／特太」一覧は撤去する。
- 書体を選び直す操作では、既存の `updateTextStyle` を通して基本太さと部分太さをその書体の実在値へ合わせる。単一ウェイトへ変更した後に前の900等が残る状態を防ぎ、部分範囲の位置と文字の配置は保持する。フォント情報の読込自体では作品を更新しない。
- 保存値は既存の `fontWeight` と `text_weights` を使う。編集・検証・読込は1〜1000の整数を受け付ける。プリセットの候補は既存のCSSフォント順から解決し、描画・Undo・保存の別経路は追加しない。
