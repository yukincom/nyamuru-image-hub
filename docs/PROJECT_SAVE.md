# 作品フォルダへの保存

Mac側のローカル連携は `.nyamuru/project.json` と原本、LAN側の編集PCはフォルダー直下の `project.json`（画像込みJSON、上限192MiB）を使います。両者は配置・原本管理が異なります。以下はMac側の保存説明です。LAN側の旧名互換・競合条件は [LAN編集](./LAN_EDITING.md)を参照してください。

ローカル起動版では、ヘッダーの「保存」と ⌘S / Ctrl+S は同じ操作です。新規作成で指定したエピソードフォルダへ、作品・作画設定・ネームに配置した人物と文字の切り抜き画像をまとめて保存します。

- 内部データは保存先直下の `.nyamuru/project.json` に置きます。通常のFinder表示には出ません。個別に開いたり編集したりする必要はありません。
- 「開く」でエピソードフォルダを選ぶと、作品・作画設定・切り抜き画像を復元します。シリーズフォルダではなく、その話の保存先を選んでください。
- 保存先がまだ結び付いていない既存作品は、初回の保存でフォルダを選びます。以後は作品IDと保存先の組を端末で記憶します。ブラウザデータの削除やフォルダ移動後は「開く」で再選択してください。
- 同じ保存先を選び直した場合は既存の登録を再利用し、登録を増やしません。登録に失敗した選択は採用せず、選び直して再試行できます。
- 保存先の確認・変更は「環境設定 → データ管理」にあります。変更操作は、新しい保存先への保存も行います。
- ブラウザへの自動一時保存は引き続き行いますが、フォルダ保存やバックアップの代わりではありません。

保存は一時ファイルの書き込みが完了してから置き換えます。別作品のあるフォルダ、別タブ等で更新された保存ファイル、参照画像の不足は上書きせず通知します。保存中に追加した編集は画面に保持し、次の保存で反映します。画像込みJSONはローカル連携の既存上限96MiB以内です。

シリーズ台帳は内容・名前・資料参照が変わらなければ再書き込みせず、更新日時も保持します。変更がなくてもrevisionの競合と指定された資料参照は検査します。

シリーズ台帳の新規保存名は `series.yaml` です。既存の `series.omny.yaml` だけがある場合も開けます。開くだけでは変更せず、明示保存すると新しい名前へ保存し、旧ファイルは保持します。両方がある場合は、移行時に記録した旧ファイルのハッシュが一致するとき、または移行記録がなく両方の内容が完全に同じときだけ読み進めます。食い違う場合は自動選択・上書きをせず通知します。移行後に旧ファイルを変更すると競合になるため、両方を保管して内容を確認してください。

シリーズ保存でmetadataの置換に失敗した場合は、準備済みの一時データから直前の台帳へ戻します。復元の置換にも失敗した場合は元データを消さず、その場所をエラーに表示します。この場合は再保存を続けず、表示されたデータを保管して復旧してください。電源断やOS障害に対する2ファイル同時更新の保証ではありません。

シリーズ共通の人物資料画像・人物台帳、作画用ラフの制作台帳、原文確認reportと元資料は、それぞれ既存のシリーズ／エピソード配下に保持します。この保存ファイルへの一括移動はしません。原文確認の入力・画面内の未保存の確認状態は「開く」で引き継がれないため、原文確認reportはその画面の保存操作を利用してください。作品のバックアップや別PCへの移動では、隠しフォルダを含めたシリーズ／エピソード全体を保管してください。

## YAMLファイルの書き出し・作画設定の受け渡し

「環境設定 → データ管理 → 構成データを書き出す」は、作品の構成・セリフを `作品名.yaml` へ書き出します。画像原本・作画設定は含まず、作品フォルダの完全なバックアップではありません。構成YAMLをファイルから読み込む画面はありません。作品を再開するときは「開く」で作品フォルダを選びます。

「環境設定 → 作画設定（YAML）」では、OFFの候補も含めた控えを `作品名-settings.yaml`、有効な作画ルールと仕上がり仕様を含む生成指示を `作品名-generation.yaml` として書き出せます。設定ファイルの読み込みは候補の追加で、現在の設定を上書きしません。構成データと作画設定を画像生成へ渡すときは、両方を用意します。

単一HTML版でも明示的なYAML書き出しを利用できます。Mac側のフォルダ保存・読込にはローカル起動管理とbridgeが必要です。LAN版は編集PCのブラウザーからフォルダを選びます。通常の保存にモデルの推論は不要で、Mac側へ作品を送らないLAN保存の手順は [LAN編集](./LAN_EDITING.md)を参照してください。
