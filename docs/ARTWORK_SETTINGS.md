# レイアウト・テキストと作画方法

環境設定では、最終原稿の仕様とAIで作る範囲を別のタブにする。
表示しただけでは作品を変更しない。作画方法を切り替えても原本・入力済みの数値を削除しない。

## 画面

- 「レイアウト」：用紙の幅・高さ、dpi、片側の塗り足し、コマ枠線・コマ間隔。
- 「テキスト」：書体、フキダシ線幅、見出し・作者名のサイズと作者名の位置、強調テキストの倍率。
- 読み方向・テキスト方向は内部の固定値として保持し、設定欄を表示しない。左綴じ・横書きの切り替え機能は提供しない。
- 「作画方法」：ラジオボタンで「完成原稿を生成する」「下書きを生成する」を選ぶ。
  - 完成原稿：ページ全体を文字・フキダシ込みで仕上げる指示。
  - 下書き：コマごとに独立した線画を作り、手描きで描き直し・加筆する指示。文字・フキダシなどは画像に焼き込まず、元の文字データを保持する。
- 出力形式の解釈・人物演技と背景の区別は、既知の内部ルールとして適用し、チェック欄を表示しない。
- 画風変更時の人物の特徴と独自の追加候補はチェックで反映する。OFFは削除ではない。
- 詳細背景の上限は完成原稿を選んだときだけ表示する。完成原稿専用の追加候補は、下書き中にはチェック状態を保持したまま無効化し「完成原稿でのみ反映」と示す。

## 共通の仕上がり仕様

`manga.finish_settings` は幅・高さ（mm）、解像度（dpi）、塗り足し（片側mm）の正本。
未設定時は最初のネームの用紙寸法、300dpi、塗り足し0mmを表示する。ページがなければ210×297mm。
値は編集したときに初めて保存する。自動で印刷所の規格に合わせる設定ではない。

`getFinishLayout()` が生成用の共通 `finish_layout` を組み立てる。
書体・線幅・コマ間隔は `manga.meta`、見出し等の数値は作画設定の原本を参照し、二重管理しない。
数値欄は既知の書式だけを扱う。未知の文章から推測して数値を書き換えない。

- 仕上がりpxは `round(mm × dpi / 25.4)`、塗り足し込みは幅・高さにそれぞれ両側分を足す。
- ネームの座標と画像配置は書き換えない。`page_transforms` に元の寸法と最終寸法へのX/Y換算率を出す。
- 最終配置時の線幅・文字寸法は最終原稿上のmm。座標の倍率を二重にかけない。
- 用紙の縦横比を変えるとX/Yの換算率は異なる。自動のコマ組み直し・トリミングは行わない。
- 塗り足しは仕上がり線の外側への描き足し。コマのタチキリ指定とは別。
- `finish_layout` は書き出し時の派生値。再読込では保持せず、次の出力時に正本から再計算する。

## 作画設定の原本とモード

`manga.artwork_settings`（version 1）の `groups` に名前・適用範囲・ON/OFF、`fragments` に元の順序で本文を保存する。
`mode` は `integrated` / `draft`。未指定の旧データはページルールのON/OFFから表示を決める。
数値変更は原本の対応箇所を更新し、モード切替では原本を変更しない。

`compileArtworkForMode()` が選択モードを生成用の本文へ投影する。
完成原稿ではページルールを適用し、下書きでは完成ページ・後加工禁止などの指示を除き、手描き仕上げ用の指示を加える。
既知の内部ルールは、原本のチェック状態を変えず有効にする。
`applyArtworkSettings()` はこの結果を `meta.style_notes` と `layout_spec` へ反映する。

互換用の低レベル `compileArtworkRules(settings, target)` は保存されたON/OFFだけに従う。
`integrated` はONの共通＋専用、`character` はONの共通のみ。UIのモード選択を使う側は `compileArtworkForMode()` を使う。
独自の追記や未知の規則は共通へ勝手に移さず、完成原稿側に保持する。

## 保存と書き出し

- 通常のフォルダ保存（`.nyamuru/project.json`）と `toStoredMangaYaml` はモード・仕上がり仕様・OFFの原本を保持する。
- `toMangaYaml` は選択モードの本文、`toSeparatedMangaYaml` は本文抜きのネーム。どちらも設定済みの仕上がり仕様を共有し、編集用原本は含めない。
- `toOmayYaml(document)` は選択モードの生成用OMAYと共通の `finish_layout`。明示した `character` target は共通の本文のみ。
- `toArtworkSettingsYaml` はOFFの原本も含む作画設定の控え。用紙・dpi等は作品側の設定なので、この控えには含まない。
- シリーズカタログに作画設定・エピソードの仕上がり仕様を持ち込まない。
- 生成向けの書き出しは編集用の完全バックアップではない。再編集には通常のフォルダ保存を使う。

ファイルと標準設定の読み込みは、現在の原本を置き換えずOFFの候補として追加する。
同一の原本は重複追加せず、現在のモードやチェック状態を上書きしない。

## 接続境界

ここで実装するのは設定UI・保存・生成指示の出力まで。
画像・印刷・PSDの出力側が同じ `finish_layout` を参照できる契約であり、新しい画像生成エンジンや印刷・PSDレンダラーではない。
既存 `panelDraft.ts` のAnimagine固定4値ラフは別の専用プロファイルで、この選択では切り替わらない。
ラジオボタンの変更・設定の読み込みによって、画像生成・外部送信・モデルダウンロードは実行しない。

## 生成向けの言語

生成用OMNY/OMAYでは、同梱の固定ルール・下書きの指示・仕上がり仕様の説明を英語で出す。
画面上の日本語ラベルや、保存済み作品の編集用原本は変更しない。
既知のルールは完全な行単位の翻訳表で対応させ、文字サイズなどの可変値はそのまま引き継ぐ。
英語の書き出しを読み戻すと、既存の項目分類・数値入力が使える編集用表現へ復元する。

- 定義済みの出力形式は `color manga` / `black-and-white manga` / `grayscale manga` で出す。
- タイトル・作者名・セリフ・画面内文字・人物名・素材キーは作品の原文・参照識別子を保持する。
- 書体名も実際のフォント識別子を保持する。アンチック体の混植指定は英語のルールで説明する。
- 作者が書いた独自のルール、演技・背景・容姿の自由文は、この固定翻訳表で推測して翻訳しない。
- 画像生成の出力品質改善を保証するものではない。翻訳処理はモデルを呼び出さず、作品を外部へ送らない。
