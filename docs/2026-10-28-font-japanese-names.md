# 書体パレットの日本語名称

2026-10-28。4列表示の利用者確認後、`3bae690` を回復点として着手。

- 既存のLocal Font Access → PCフォント一覧 → 書体パレットの経路へ、日本語の表示名を追加する。
- フォントの `name` テーブルから日本語のファミリー名を読み取る。ブラウザーが返すファミリーに対応する名称を選び、太さ別の名称を広いファミリー名へまとめない。日本語名が無い場合や読み取れない場合はブラウザーの名称を使う。
- 一覧・サンプルの下の名前・選択中のボタンを表示名で描画し、表示名で並べる。選択値、CSS、作品の保存値は既存のファミリー名を使う。
- 既存の端末フォント一覧キャッシュへ表示名を保存する。同じフォント構成でも名称が変われば更新し、作品履歴や作品保存は動かさない。
- 読み取るのはフォントのディレクトリーと名称テーブル。大きい字形データをJavaScriptへ展開せず、取得は最大4件ずつ実行する。

参照: [Local Font Accessの国際化](https://wicg.github.io/local-font-access/#internationalization-considerations)、[OpenType nameテーブル](https://learn.microsoft.com/en-us/typography/opentype/spec/name)。
