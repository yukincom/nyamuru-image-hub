## `overflow: hidden` の経緯

`src/styles/global.css` の人物・フキダシ・画面文字に共通する編集要素ルールへ、2026-10-24 13:00:28 +09:00 の commit `bb1ac4bb` で `overflow: hidden` が追加されていた。これは利用者指定のフキダシ仕様ではなく、要素共通スタイルへまとめた際にフキダシまで対象になったものだった。選択中だけ `.is-element-selected { overflow: visible; }` へ切り替わるため、ベクターしっぽが非選択時だけ編集枠で切れていた。

修正では共通ルールからクリップ指定を分離し、人物と画面文字は従来どおり `hidden`、フキダシは常時 `visible` とした。紙面自体とコマの明示的なクリップは変更しない。
