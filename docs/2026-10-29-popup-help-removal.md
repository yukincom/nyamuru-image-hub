# 説明ポップアップの削除

2026-10-29。[方針](2026-10-29-popup-help-policy.md)と[削除前の一覧](2026-10-29-popup-help-inventory.md)を `2ecc880` に保存した後、利用者の指示により実装した。

## 変更

- 既存の `PaintToolHelp` を、ツールボックスの名前と短いキー案内だけに限定。レイヤー、文字設定、線設定、3D設定などの長い説明を撤去した。
- HTMLの `title`、SVGの補助的な `title`、3Dスコープへの動的な `title` を撤去した。公開ガイドのホバー説明も対象に含む。
- ボタン名・読み上げ用の名前・クリックで開くメニュー・設定ダイアログ・確認やエラー通知は保持した。キー案内には既存の「編集ガイド」ON/OFFが適用される。
- Shift操作の計算、ネーム取込の解析と編集開始は変更していない。非公開マニュアルも変更していない。

## 確認

- 関連Nodeテスト51件成功：`textToolMenu`、`paintPreferences`、`pageLayerPalette`、`vectorGeometry`。
- 変更したTypeScript/TSX/Astro計31ファイルの型診断：エラー0・警告0。削除によって不要になったimportも除去し、そのファイルを再確認した。
- AST検査：コンポーネントの標準 `title` 属性0、SVG `title` 0、`data-tool-help` 0。残るキー属性は道具欄の定義だけ。
- 実ブラウザー32項目成功：hover/focus、Escape、ツールボックス以外の非表示、図形と文字のメニュー、分布8ボタン、編集ガイドのOFF/ONと再マウント、3D設定の開閉と説明非表示。
- 全ソース差分の読み取り専用レビュー済み。途中で見つかった分布の下端・右端ボタン2個の誤削除を復元し、画面で8ボタンを確認した。
- TSX差分27ファイルのイベントハンドラー747個・操作条件/値の属性458個が変更前と同一であることをASTで照合した。
- `git diff --check` 成功。ビルドと全件テストは利用者確認前のため実行していない。

ブラウザー検証は `tests/paintToolHelp.vite.mjs` を使い、127.0.0.1:4341の専用画面で実施した。検証設定は既存の `EditorApp` にexportを付けるだけで、処理本体は変更しない。起動入力は合成文書、操作は合成イベント。外部サービスは遮断し、実作品の読み書き、モデル生成、3D撮影はしていない。再マウントで確認したのは端末の編集ガイド設定であり、作品の保存・再読込ではない。

既存の `backgroundEditor.browser.tsx` も説明表示を要求しない期待へ更新し、型診断を通した。撮影・保存を含む同ファイル全体は今回実行せず、説明の非表示と開閉は上記の32項目で確認した。
