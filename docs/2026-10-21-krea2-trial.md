# Krea2の試行と終了（2026-10-21）

公開されていた多視点の人物設定画の作例を参考に、2026年9月にKrea2で小雪の人物資料を使う画像編集を試した。途中でより有望と判断したQwen Image 2.1系が登場したため移行し、Krea2の試作は中止した。現在の生成は[Qwen Image 2.1 Turboに統一](2026-10-21-image-generation-cleanup.md)している。

## 試した組み合わせ

| 役割 | 使用したもの |
|---|---|
| 画像生成 | Krea 2 Turbo BF16 |
| 人物参照編集 | Krea 2 Identity Edit v1.2＋`comfyui-krea2edit` |
| テキスト・画像エンコーダー | Qwen3-VL 4B BF16 |
| VAE | 既存のQwen Image VAE |
| 実行環境 | ComfyUI 0.32.0、PyTorch、MacのMetal/MPS |
| 参照素材 | 自作の小雪の人物画。既存のAnimagine用LoRAは使用しない |

最初の単一参照による2枚は人物や線の特徴が残る一方、顔向き・腕のポーズの変更は弱かった。これは目指した多視点資料の実験と条件が異なり、モデル全体の能力不足を示す比較ではない。その後、人物資料の組み直しやアプリへの組み込み、複数参照時のメモリ対策も試したが、Qwen系へ移行した。

この短い記録を残し、Krea2専用のコード・モデル・複製素材・生成物・ジョブ／キャッシュ・詳細手順を撤去した。自作原画と、他の用途でも使うPython環境・VAEは保持した。
