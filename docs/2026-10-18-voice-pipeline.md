# 音声・文字からニャムルを操作する

**2026-10-20の導入・動作確認は [seed43の導入記録](2026-10-20-voice-seed43.md) を参照。以下はv0.2を使った2026-10-18時点の記録です。**

2026-10-18。開発版の接続は `マイク→Whisper→入力欄` または `文字入力→入力欄`、続いて `実行→ModernBERT分類→引数確認→既存の編集処理`。

ヘッダーの「音声・文字操作」を開き、一つの操作を入力して「実行」を押す。音声は「音声で入力」で開始し、停止後に文字起こしを確認・修正できる。セリフの口述入力とは別の操作欄で、勝手に送信しない。閉じると録音を止め、待機中の分類結果も適用しない。

## 現在つないだ操作

| 例 | 実行先・範囲 |
|---|---|
| 保存して | 通常の保存処理。描画反映・保存先・競合検証を共有し、キャンセル・失敗もその結果を表示 |
| アンドゥして／リドゥして | 通常の編集履歴。対象履歴がなければ変更なし |
| 2ページに移動して | ページ一覧と同じ切替。番号は原稿のページ番号で照合 |
| 内枠スナップをオンにして | 内枠スナップ／コマスナップ／コマシンクロの現在値を確認して設定。繰り返しても反転しない |
| ガイドを非表示にして／見開きを表示して | 既存の表示設定 |
| 下書き生成に切り替えて／一体生成にして | 作画方式の設定だけを変更 |
| ベクターペンに変えて／ラスターペンに変えて | 開いているペイントの既存ペン選択。原画形式は変換しない |
| この吹き出しを四角にして | 選択中の既存フキダシの形。丸・四角・ナレーション・トゲに対応 |
| この吹き出しに「新しい本文」と入れて | 選択中の本文を原文どおり変更。引用内の操作語は本文として保持 |
| これを生成して | 選択中の人物・フキダシの生成準備画面を開く。画像生成の開始はその画面で行う |

未選択・非表示・ロック・処理中など既存の制約を守る。分類を待つ間に原稿、ページ、選択、描画内容、設定が変われば適用しない。

表は実行処理で受け付ける言い方。暫定BERTが別のラベルに分類した場合やスコア不足の場合は保留するため、すべての例の実行を保証するものではない。

複数操作、内容に応じた素材・3D候補の選定、複数文字枠の上端揃えは未接続。ページ全体生成や未指定の対象を既存機能で代用しない。今回の接続は単独で指定の明確な言い方に限定し、引数を確定できないときは未実行と表示する。

## ローカル導入

モデルは提供された `nyamuru-voice-v02-colab-results.zip` のtrial 4（seed43）。開発用macro F1で選んだ暫定版で、95%を達成したモデルではない。既存の19ラベルIDを固定し、v0.3の学習とは分離する。

```sh
python3 scripts/install_voice_intent.py /path/to/nyamuru-voice-v02-colab-results.zip
npm run dev
```

インストーラーは確認済みZIPのSHA-256を照合し、`models/nyamuru-voice-v02/`へ4ファイルと出典を置く。重みはGit対象外。別モデルへ変更するときは19ラベルと評価結果を確認し、`NYAMURU_VOICE_INTENT_MODEL`でローカルフォルダを指定する。

分類用Pythonは既存の兄弟`ComfyUI/.venv/bin/python`を使う。`NYAMURU_VOICE_INTENT_PYTHON`で変更可能。実装はPyTorch/TransformersのCPU推論を子プロセスで行い、完了・タイムアウトで終了する。ネットワーク取得、パッケージ追加、常駐LLMの起動・停止は行わない。

音声には既存の`ffmpeg`、`whisper.cpp`、Kotoba Whisper、Silero VADを使用する。配置を変える場合は `NYAMURU_VOICE_FFMPEG`、`NYAMURU_VOICE_WHISPER_CLI`、`NYAMURU_VOICE_WHISPER_MODEL`、`NYAMURU_VOICE_VAD_MODEL`を指定する。録音・一時音声は保存用データに含めず、文字起こし完了時に一時ファイルを削除する。

HTTP入口は既存bridgeの `/api/voice/transcribe` と `/api/voice/classify`。bridgeの起動・終了は既存supervisorのleaseを再利用し、操作そのものはブラウザーの既存処理に渡す。分類器が作品ファイルを直接変更することはない。

## 検証と制限

BERTのsoftmaxスコアは正解率ではない。暫定的に0.9未満を保留し、それ以上でも単独操作として全文と引数を確認する。v0.2で誤分類した否定・延期・複数操作を回帰テストに含める。この制御によって、自由な言い換えの一部も保留になる。

分類入力は原文だけ。slots・正解ラベルを入力へ混ぜない。4000文字、256トークンを上限とし、超過時は切り捨てず拒否する。自動実行の成功率と実マイクの認識率は分類モデルの評価とは別に測る。

モデルなしの回帰確認:

```sh
node --no-warnings --experimental-strip-types --test tests/voiceCommands.test.mjs
python3 -m unittest tests/test_voice_intent_bridge.py tests/test_editor_voice_bridge.py
npm run verify
```

隔離原稿での実画面確認は、通常の`npm run dev`で起動するsupervisorを使い、別ターミナルで `node node_modules/vite/bin/vite.js --config tests/voiceCommands.vite.mjs`、`http://127.0.0.1:4338/tests/voiceCommands.browser.html`を開く。合成原稿だけを独立originのlocalStorageに置き、実bridge・実BERT・実Appを使用する。保存先を選ぶ場合は検証専用の空フォルダを指定する。起動した検証サーバーは終了時に停止する。
