# Qwen生成をTurboへ統一（2026-10-13）

通常生成・ペイント参照・ネームの人物ラフからの生成は、すべてQwen-Image-2.1 Turboを使用する。既存のQwenジョブと実行環境を使い、モデルやAPIは追加しない。画面も全モードでTurboと表示する。

| 入力 | 解像度の基準 | 生成条件 |
|---|---|---|
| 通常生成 | 1024相当・配置先の縦横比 | Turbo / 8 steps / CFG 1 / Euler / 公式固定sigmas |
| ペイント参照 | 1024相当・描画画像の縦横比 | 同上 |
| ネームの人物ラフ | 768相当・ラフの縦横比 | 同上 |

seedは260921。CPU VAEとメモリ保護（開始時の空き21 GiB、実行中の空き6 GiB、swap増加1 GiB、MPS割当上限16 GiB）を全モードで使う。通常生成・ペイント参照の指示文と透過方法、およびラフの完成画RGB＋追加工程alphaの合成は変更しない。

過去の通常版40ステップのジョブは、保存済み入力・英訳・画像のSHAを保持したまま履歴の参照、画像取得、明示的な削除を行える。未実行の通常版ジョブはそのまま再開せず、「新しい生成を準備してください」と案内する。新規生成とその事前確認はTurboのみを要求し、通常版モデルファイルへフォールバックしない。実験用labの設定と通常版モデルファイル自体は変更・削除していない。
