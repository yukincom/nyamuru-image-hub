# 選択・文字・フキダシ操作の更新（2026-10-25）

## 変更内容

- ツール名を「パス選択」から「選択」に変更した。
- `V` は選択したベクター要素全体を移動・拡大縮小する。青い外接枠と辺・四隅のハンドルを表示し、`Shift` を押している間は縦横比を保つ。
- `A` は既存どおりノードを編集する。`V` / `A` の青いパスとアンカーはコマ枠で切れずに表示する。
- `V` は黒い矢印、`A` は白い矢印のカーソルで区別する。ベクターの選択パス・アンカー・外接枠は、フキダシのダイレクト選択と同じ青（`#236bc4`）に統一した。これは編集用の重ね表示だけで、確定後の線色・塗りには反映しない。
- 文字は字形の近くでも選択しやすくし、クリック時に `T` へ切り替える。
- `T` は吹き出しを作らない純粋な「通常文字」ツールとした。設定はドラッグ可能なフローティングウィンドウにし、別メニューを開いても維持し、別ツールへ切り替えたときだけ閉じる。
- `T` がすでに選択済みでも、ツールボタンまたはショートカットを再度使えば閉じた文字ツールウィンドウを開き直せる。
- 「吹き出しを追加」は廃止した。通常文字へ素材を被せるか、紙面上でフキダシのパスを作って文字を入れる。素材の適用または通常文字の取り込みが終わると、自動で `V` の選択状態へ戻る。
- フォント一覧は正式名を省略せず表示し、行間を詰めた。フォントや太さの変更ではフキダシの位置・形を変えない。
- 文字ツールウィンドウは従来のおよそ半分の幅へ縮めた。通常文字／フキダシの切り替えと追加操作はアイコンだけにし、説明はポインターをしばらく置いたときのツールヘルプだけに表示する。重複していた常時表示の説明文は削除した。
- フキダシ側では線幅を先頭に置き、素材一覧を別窓ではなく同じウィンドウへ内蔵した。素材は2列のスクロール一覧とし、フォントの選択肢も狭い幅で読めるタイルへ詰めた。
- `V` で選択したフキダシは、フォント描画後の可視画素ではなく保存済みの `bbox` を青い枠とリサイズハンドルに使う。フォント変更による枠のずれを防ぎ、四隅から安定してサイズ変更できる。
- コマ枠の四隅を示す青い印は、クリック可能な範囲を維持したまま見た目だけ従来の 1/8 に縮小した。
- 書体は `text_style.font`、選択文字の太さは `text_weights` へ保存する。フキダシの太字範囲から `emphasis` を自動生成し、編集画面の選択をOMNYの正本とする。インスペクタには形・強調フレーズ・ベジェ作成欄を重複表示しない。
- フキダシのしっぽは「なし」「通常」「思考」を明示的に選べる。思考しっぽは 2〜4 個の丸で表示する。
- シナリオ一致が確定済みのフキダシには候補欄を出さない。要確認だけに候補を表示し、対象の前後コマの文字も候補順位へ使う。本文を編集した時点で要確認を解除するため、「確認済み」「シナリオを見る」の個別ボタンは置かない。
- ト書きやセリフから形を自動変更する機能は削除し、互換用の呼び出し経路も残さない。形は素材または紙面上のパスで決める。インスペクタの「ベジェで輪郭を作る・編集」は廃止し、紙面上の `A` による既存パス編集だけを残す。
- ペン設定の行間を詰め、同じ操作をより小さい領域に収めた。

## 確認

## 設計メモ

`V` の役割は Adobe Illustrator の選択ツールと同様に、個別ノードではなくオブジェクト全体の移動・変形とした。`A` は紙面上に存在するノードの直接編集に分け、インスペクタに別の輪郭作成経路は持たせない。

選択表示の履歴を調べると、ベクター編集用の重ね表示そのものは 2026-09-27 20:25:06 +09:00 の commit `0e575db` で追加され、選択頂点を暗色で塗る指定は 2026-09-29 19:12:16 +09:00 の commit `49ad8a3` で追加されていた。今回見えていた白線と黒い頂点は作品データの破損ではなく、編集用オーバーレイの配色だった。描画データの黒線・塗りなしは維持し、オーバーレイだけを青へ変更した。
