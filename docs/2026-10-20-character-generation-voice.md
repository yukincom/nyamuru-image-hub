# キャラクター生成への音声・会話接続（2026-10-20）

「このキャラクターを生成してください」は、現在選択している人物の生成準備を開く。「1コマ目の小雪を生成してください」は、表示中のページの1コマ目にある小雪の配置を探し、同じ生成準備を開く。画像生成の開始は、開いた画面で条件を確認してから行う。

## 原因と修正

実際の分類器 `nyamuru-voice-v04-seed43` は「このキャラクターを生成してください」を `generate_request`、confidence 1.0 と判定した。分類後の引数解決が「これ」「選択中の人物」「選択中の吹き出し」だけを受け付けていたため、依頼が会話へ流れていた。会話へ渡す状態も選択中のフキダシだけで、人物選択や現在ページの人物配置が欠けていた。

- 「この／選択中の／今選択している／今選んでいる」人物・キャラクター・キャラを、既存の `generate_selected` へ接続した。
- コマ番号と人物名は現在ページ内で解決する。番号は1始まりのコマ順。配置名と、紐付いたキャラクターの名前・別名を完全一致で照合する。同名配置が複数ある場合は選択を求め、推測しない。
- 既存の `requestOwnerGeneration` と生成条件画面を使い、モデル・HTTP入口・生成プロンプト・分類用学習データは変更しない。
- 生成準備を開いた結果や失敗はそのまま返し、追加の会話推論を待たない。
- 会話へは選択種別、選択人物の名前・設定、現在ページ内の人物配置を渡す。画像データやローカルファイルパスは渡さない。

否定・保留・引用・複数操作は単独の生成指示として扱わない。存在しない対象、種類違い、非表示・ロック中の対象は開かない。分類を待つ間に選択や原稿が変わった場合は、既存の取消し処理で停止する。

対象テスト30件が成功。型検査は403ファイルでエラー・警告0件（既存のヒント2件）。実ブラウザーの検証原稿と稼働中のseed43分類器で、選択中の人物への依頼、および2コマ目を選択した状態から「1コマ目の小雪」の明示指定の両方が、コマ1・小雪の既存生成画面を開くことを確認した。画像生成そのものはこの確認では実行していない。
