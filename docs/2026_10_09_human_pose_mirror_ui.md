# 体勢の鏡反転とUI計画（2026-10-09）

利用者の追加指定により、今回は体勢の鏡反転と節比較を純粋関数として実装し、左右クリックのUIはP5の計画へ記載した。3D yaw回転は今回の左右入替操作に含めない。

## 実装

`src/lib/humanPoseMirror.ts` の `mirrorHumanPoseBody(rig, pose)` は元の値を変更せず、新しいposeを返す。rig signature・base hashと全boneの対応を確認する。

- 素材座標のX=0を鏡面にし、rest行列を基準に左右の骨の変形を入れ替える。全出力のscaleは正の1に保つ。
- 頭の位置は体勢へ追従する。headと表情を含む子boneの世界方向を保持し、顔向きは体勢と別に扱う。
- 支持物・足/手/肩/座面/背面の接触点とL/Rを同時に入れ替える。cameraは変更しない。
- 作品内の配置は外側のtransformへ分離する。この関数へ配置済みrootを渡すと、root.xも原点の反対側へ動くため、人物中心での配置操作にはそのまま流用しない。
- 確認済み素材からの一時的な派生表示用。ファイルの採用・保存、利用者の撮影確認は呼出し側で扱う。

首と頭の混合weight部分は、顔boneの方向が同じでも首の追従によって変形する。代表例の頭部下端では、単純な平行移動との差が最大約3.21mm。顔表面全体の剛体保持を保証する実装ではない。

`src/lib/humanPoseClauses.ts` の節比較は [別記](2026_10_09_human_pose_clause_diff.md)。`,` / `、` で区切った内容を一対一で比較する。全文が変わったという理由だけで全節を変更扱いにしない。日英の節対応と翻訳呼出しはP5の残作業。

## UI計画

[P5](2026_10_08_human_pose_p5_generation_integration.md)へ、右サイドクリックで右向き、左サイドクリックで左向きの選択を追記した。同じ側の再クリックでは状態を維持する。顔・目線、人物の配置、cameraとは別値で保存する。画面、保存形式、HTTP、LLMの接続は今回実装していない。
