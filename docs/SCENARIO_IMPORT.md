# シナリオからセリフ・ト書きを取り込む

新規作成で明示的に反映した `origin_name.md` の `# シナリオ` を、対応する本文の正本として使用する。OCRは吹き出しとの対応付けに使い、対応が決まらない本文は仮入力として残す。資料を選び直しても、作成済み作品の本文を自動で再上書きしない。

```md
# 作品名
## あらすじ
友人と再会する。

# シナリオ
## page1
### コマ１
春「明日は**学校**へ行こう」「また会おう」
春は窓を指す。
```

- `page1` / `1ページ` と `コマ1` の番号を使う。見出しの全角数字・全角空白・全角＃も受け付ける。
- `名前「セリフ」` を抽出し、連続するかぎ括弧にも話者を引き継ぐ。かぎ括弧内の改行を保持する。
- `**フレーズ**` のマーカーだけを除去し、既存の「強調するフレーズ」に登録する。複数箇所はカンマ区切り。
- それ以外の文章は、同じページ・コマのト書き（`panel.action`）へそのまま入れる。人物ごとの演技を意味推論で再配分はしない。
- シナリオ区間はタイトル・舞台設定・あらすじの抽出から分離する。コードブロックは本文として解釈しない。文章や画像内の指示は実行しない。

## 自動対応

OCRのコマ所属と文字領域の配置が確定し、シリーズ人物を読み込んだ後に適用する。

- 同じページ・コマの中で比較する。他のコマから似たセリフを流用しない。
- 照合用キーだけNFKC・大小文字・空白/改行・通常の句読点等の差を吸収する。記号だけのセリフは空文字へ潰さない。
- 一致率は `1 − 編集距離 / 長い方の文字数`。意味の一致確率ではない。
- **70％以上**で一意かつ他の吹き出しと競合しない最良候補を自動反映する。同点や競合を読み順だけで強制確定しない。
- 同一話者の隣接する最大4セリフは、一つのOCR領域との結合比較も行う。採用本文は各セリフを改行で連結する。
- 名前または別名が一意に対応すれば、キャラクターの正規名とローカルIDを話者に設定する。未知・重複の名前は推測しない。
- 成功した吹き出しは正本の文字を表示する。OCR原画は削除せず参照表示を切り替えられる。

## 人が選ぶ場合

70％未満・同点・競合・未読の吹き出しは、本文の直下に候補が表示される。候補ボタンを押すと本文・話者・強調を反映する。選択済みの候補は折りたたまれ、他の吹き出しでは使用済み候補を除外する。シナリオ画面でも対応を選べる。

未対応のOCR本文も表示・保存・生成に使用できる。シナリオにないセリフはエラーではなく、「この本文を使う」か直接編集で使用を確定できる。改行や手入力も保持し、OCRの控えは変更しない。読み落とされた吹き出しを手動で追加した場合も未使用の候補を選べる。「対応だけ選び直す」は本文・位置を消さずに関連付けを解放するので、誤った対応の入れ替えにも使える。サムネイルの「確認 N」は入力の検証項目数であり、シナリオ不一致数ではない。

ページ前景はコマが確定しないため同じページ内から手動で対応させる。未検出のページ・コマ・吹き出しを勝手に生成せず、正本を「対応する吹き出しが未指定」として残す。

未登録の話者表記は、一度だけ対応する登場人物を選ぶことで、この作品内の別名として記憶し、対応済みのセリフにも適用する。

## 保存と外部出力

正本と元のOCR文字、対応ID・一致率・手動確定状態は、作品の `manga.scenario` / `bubble.scenarioMatch` としてブラウザ自動保存・フォルダ保存に保持する。読み込み直してもOCRで本文を再上書きしない。

生成用OMNYには、現在の本文（OCR仮入力・手入力も含む）・話者・強調・ト書きを含める。正本全文と照合の控えは除外する。照合に追加モデル・外部API・新規依存ライブラリは使用しない。文字列監査はシナリオ未読込時の折りたたみ補助機能として残す。

## 人物の演技・背景

人物画像の読み取りは完了人数のバーと現在の人物の経過秒数を表示する。新規作成に追加の推論パスは加えない。ト書きはコマ全体の文脈としてラフ生成へ渡し、複数人の動作を全員のactionへ複製しない。

「コマ XXの人物へ注入」は、既存ローカルLLMで表示中のコマのト書きと人物別actionをすり合わせ、重複のない完成文へ置き換える明示操作。画像読み取りの確かな描写を保持し、曖昧な解釈をト書きの明示情報で補い、「怪訝」などの具体的な表情の言葉を残すよう指示する。セリフ、現在の人物action、取り込み済みのト書きを渡し、台本原本全文や元画像は送らない。完成文が4000文字を超える場合や、回答の対象人物が一致しない場合は一人も変更せず通知する。空の回答で既存actionを消さず、処理中のコマ編集やコマ移動があれば適用しない。背景・フキダシ形・ト書き・座標は変更しない。

背景の「簡易」「詳細」で情報が未指定なら、エピソードの「場所」を初期値にする。個別に入力した背景や明示的な空欄を上書きしない。「感情・効果」「描写なし」には場所を補完しない。
