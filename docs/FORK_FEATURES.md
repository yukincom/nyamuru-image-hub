# アナログネーム取り込みフォークの機能

この文書は、[本家Nyamuru🐱 Manga Name Studio](https://github.com/sa-san10/nyamuru-manga-name-studio)へ本フォークが追加した機能、ローカル依存、既知の制限をまとめたものです。NDM・OMNY・OMAY・生成プロンプトなど、Nyamuru本来の仕様は本家プロジェクトを正とします。

## 目的

完成済みのアナログネームを、作り直すのではなく短時間で編集可能なOMNYへ変換します。解析結果は完成データではなく、利用者がコマ・人物あたり・フキダシを確認して修正するための開始地点です。

## 動作モード

| モード | 利用できる機能 | 必要なもの |
|---|---|---|
| 通常のNyamuru | ネーム編集、OMNY／OMAY入出力、生成プロンプト、コマ編集支援 | Node.jsとWebブラウザ。ビルド済みサイトではブラウザのみ |
| 手動画像取り込み | 画像の回転確認、コマ・人物・文字のローカル解析 | 通常環境＋ローカルbridge＋RT-DETR＋NDLOCR-Lite |
| macOSスキャナー取り込み | イメージキャプチャの起動、連続スキャンの自動受信 | 手動画像取り込み環境＋macOSのイメージキャプチャ |

通常の編集機能はローカル画像解析を導入しなくても動きます。モデルやPython環境はWeb配布物へ含まれません。

## アナログネーム取り込みの流れ

1. 「新規作成」を開き、「画像を読み込む」または「スキャナーを起動」を選びます。
2. 最大10枚の原画を確認します。見開き順のサムネイルから対象ページを選べます。
3. 必要なページだけ、左90°・180°・右90°で正立させます。向きの自動回転は行いません。
4. 上下・左右のコマ間隔と枠線の太さを設定します。
5. 「解析開始」でローカル解析を実行します。
6. 「原画」と「解析結果」を見比べ、ページごとの検出結果を確認します。
7. 「編集開始」で、検出したページを通常のNyamuru編集画面へ渡します。

解析では次の役割分担を使います。

- **RT-DETR**: コマ、文字領域、顔、身体の検出
- **OpenCV**: RT-DETRでコマが見つからない場合の輪郭補助
- **NDLOCR-Lite**: 手書き文字の認識
- **Nyamuru側の後処理**: 重複候補の除外、コマへの人物・フキダシの割り当て、読み順の整列

QwenなどのVLM、ComfyUI、生成AIサービスはこの解析経路では使用しません。

## 解析結果の扱い

- コマはA〜Zのテンプレートへ変換せず、検出した位置と形を編集開始地点にします。
- 顔と身体は、キャラクター名を決めつけない「人物あたり」として配置します。
- 同じ文字ブロックに属する複数行は、改行を保った1つのフキダシ候補にまとめます。
- OCR結果は誤読を前提とします。低確信度の結果は「要確認」として扱い、編集画面で修正してください。
- コマ・人物・文字が見つからない場合でも、元画像から推測して架空の要素を追加しません。

## コマ編集支援

### 内枠スナップ

コマの辺・頂点をA4ページの内枠へ近づけると吸着します。タチキリとして紙端にある頂点は、対応する紙端または内枠の拘束を保ちます。

### コマスナップ

コマの辺・頂点を、作品に保存された「上下の間隔」「左右の間隔」へ近づけると吸着します。アナログ取込では新規作成画面の入力値を使用し、通常のサンプルでは既存コマから推定した間隔を使用します。

### コマシンクロ（実験的）

ドラッグ開始時に接合している頂点や、同じ境界として揃っている辺を局所的に追従させます。離れたコマや次の溝へ連動を広げない設計です。

次の配置では、追従対象を一意に決められず意図どおり動かないことがあります。

- 一方が長い1本の辺で、反対側が複数コマの短い辺に分割されている
- 複数の斜め境界が近接し、どの溝を保つか曖昧
- 元原稿の頂点がわずかに離れ、開始時に接合関係を作れない

この場合はコマシンクロをOFFにし、コマスナップとShift移動で調整してください。コマシンクロは自動レイアウト修復ではありません。

### ドラッグとショートカット

| 操作 | 結果 |
|---|---|
| コマの辺をドラッグ | 2頂点を同じ量だけ動かし、辺を平行移動 |
| 多角形の頂点をドラッグ | 選択頂点を移動 |
| 四角形の角をShift＋ドラッグ | 四角形を多角形へ変換し、選択頂点を水平・垂直移動 |
| 辺・頂点をShift＋ドラッグ | ドラッグ開始位置を基準に水平または垂直へ固定 |
| コマをShift＋クリック | 合体対象を複数選択 |
| 「コマ合体」または⌘／Ctrl＋Shift＋M | 選択コマと所属フキダシ・人物を1つのコマへ統合 |

## データとプライバシー

- ファイル選択だけでは画像を解析へ送りません。「解析開始」を押した時だけ、同じ端末の `127.0.0.1:8787` へ送ります。
- bridgeは `127.0.0.1` のみに待ち受け、`localhost`または`127.0.0.1`で開いたNyamuruだけを許可します。
- 手動で選んだ元画像は変更・削除しません。
- プレビュー画像、回転情報、解析前の画像本体はブラウザの自動保存へ含めません。
- スキャン元は確定または明示的な破棄時に削除します。強制終了時だけ再接続用のファイル情報を残します。
- モデル重み、解析用仮想環境、利用者の原稿はGitへ含めません。

詳細は [LOCAL_VISION_BRIDGE.md](./LOCAL_VISION_BRIDGE.md) を参照してください。

## ホスト版・クラウド版の境界

通常のNyamuruとコマ編集支援はWebアプリとしてホストできます。ただし、現状のローカルbridgeはセキュリティ上localhostからの接続だけを許可するため、公開URLからアナログ解析を呼び出すことはできません。

クラウド版で画像解析も提供する場合は、認証、保存期間、利用規約、モデルの再配布条件を含む別のサーバー設計が必要です。本フォークはそのクラウド解析サーバーを提供しません。
