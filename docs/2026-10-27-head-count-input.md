# 等身入力の修正

- 利用者報告：新規作成の等身欄に `6.5` と入力すると `12` になる。等身に上限を設けない。
- 実画面で `6` → `.` → `5` と入力し、入力ごとの数値化で小数点が消え、`65` が `12` に補正されることを確認した。
- 既存の文書更新を入力欄から離れた時点に移し、入力途中の小数点を保持する。入力欄の上限と数値の丸めを撤去した。
- 文書の読み込み・検証、人物Markdownの取り込み、仕様書の上限12も撤去した。既存の下限1の検証は変更していない。
- `6.5` の連続キー入力とフォーカス移動後の保持を実画面で確認した。上限撤去後の `6.5`、`16`、`120.5`、`12345.5` は、文書・人物Markdown往復の対象テスト2件で確認した。
- 読み込み処理の修正反映時、開発サーバーの再読み込みで利用者の新規作成画面が初期画面へ戻った。入力途中の状態は保持できていない。
- 全体ビルド・全件テストは実行していない。既存の未commit変更は保持している。
