## 接続する既存経路

- 終了は既存の生成lease、guardian、対象ID付き取消し、ローカルsupervisorへ集約する。APIの不在と通信障害を分け、結果不明を生成成功にはしない。SIGTERM、EOF、取消しを待機中にも受け取り、履歴消失で無期限の待機をしない。
- 突然終了してfinallyが実行されない場合に備え、leaseへ所有プロセスと生成workerのidentityを記録する。次回の利用時は死んだ所有者・解放済みflock・実APIの状態を確認して後片付けし、生きている別の処理を記録だけで削除・停止しない。
- 生成画面の閉じる・Escape・キャンセル、外側からのunmount、ページ終了、Nyamuru終了を同じ取消しと終了処理へ通す。途中の候補は保持し、追加・再生成を暗黙に実行しない。
- 進捗はComfyUI標準WebSocketの `executing` 等から取得する。ジョブと候補IDを限定し、登録ワークフローのnode名から実行工程を表示する。割合は表示しない。
- 既存のジョブ照合と生成会話stateを拡張し、エージェント欄のassistant表示へ定型文として渡す。LLMの呼出しや会話履歴への大量の追記はしない。「生成状況を確認」ボタンを撤去し、自動で更新する。

公式仕様: [ComfyUI Server Messages](https://docs.comfy.org/development/comfyui-server/comms_messages)。
