# 説明ポップアップの調査一覧

2026-10-29。[方針](2026-10-29-popup-help-policy.md)を先に記載したうえで、現行ソースを読み取り専用で調査した一覧。**まだ削除・表示変更は実装していない。**

調査対象は `src/`。基点は `1db5916c8264c705ac7d3db317834fa508c2fa87` で、作業中の未commit変更を含む現行ファイルを読んだ。画面や選択状態で同じ定義が多数の行へ繰り返されるため、表は表示個数ではなく、文言・表示場所の種類を整理している。長文は要旨と明記した箇所のみ短縮し、条件分岐や反復はまとめた。ブラウザーで全状態を再現した一覧ではない。

## 一覧の見方

- **キー案内だけ残す**：ツールボックスのキー案内を短く表示する。現在の長い機能説明は削除対象。
- **削除対象**：説明ツールチップを表示しない。ボタンや機能そのものの削除ではない。
- `PaintToolHelp` は、マウスを置くかフォーカスすると約1秒後に出る共通ポップアップ。ツールボックスに限定されず、画面全体の `data-tool-help` に反応している。
- HTML/SVGの標準ツールチップは別経路。現在の「編集ガイド」のオン・オフは共通ポップアップにだけ作用するので、オフにするだけでは今回の方針を満たさない。

根拠：[共通表示](../src/components/PaintToolHelp.tsx)（12–53行）、[有効化](../src/components/App.tsx)（4102行）、[編集ガイド設定](../src/components/EnvironmentSettings.tsx)（244–247行）。

## 8. 表示される説明と混同しないもの

- `SectionTitle`・`Layout`・`EditorShell`等に渡す `title` は見出しや文書タイトル用。HTML標準ツールチップの `title` と区別する。
- `Field` の `hint`、フォームの常時表示説明、確認・失敗通知、クリックで開くメニューや設定ダイアログそのものは、この説明ツールチップ一覧の件数に含めない。
- 消しゴムを右クリックしたメニュー内にも説明文がある（「触れた部分」「交点まで」「線全体」）。自動で出るツールチップとは別なので、追加確認事項として記録する。メニュー項目そのものの削除は今回の方針に含めない。
- `PaintEditor` の `toolHelp` には、現在は別コンポーネントから表示されるベジェペン・図形用の古い文言定義もある。現在使われている経路だけを上表へ採用した。
- `PaintLayerPalette` の `help()` に「画像を読み込む」「画像をPNGで書き出す」「あたり画像表示」「固定」等の文言も残るが、現行の `icon()` 呼び出しからこれらへ到達していない。表示中の説明と誤認しないよう、未使用定義として分ける。
